# Участие в разработке курса

Этот файл предназначен для автора и участников проекта, **не для начинающего ученика**.

## Локальный просмотр сайта

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
mkdocs serve
```

Открой <http://127.0.0.1:8000>.

## Публикация

GitHub Pages автоматически обновляется после отправки изменений в ветку `main` с помощью процесса из `.github/workflows/pages.yml`.

## Проверка последовательности уроков

В каждом уроке для ученика:

1. Назови необходимые предварительные знания.
2. Не предлагай программу или команду, пока предыдущий урок не объяснил и не установил её.
3. Не предполагай, что ученик уже клонировал репозиторий курса.
4. Не ссылайся на «корень репозитория» до урока Git, где это понятие объясняется.
5. Используй неизменную структуру папок `~/University`, созданную в уроке 0.
6. Объясняй, как получить помощь при ошибке или изменении интерфейса.

## Проверка языка

**Пиши естественным русским языком, без ненужных английских слов.** В частности, не заменяй «папка», «файл», «источник», «путь», «результат», «учётная запись», «репозиторий», «настройки», «подсказка», «проверка результата» английскими словами.

Английские технические термины добавляй в скобках **при первом объяснении понятия**, если это поможет узнавать их в справке или интерфейсе. Дальше используй русское название. Не переводи собственные имена программ, точные надписи интерфейса, команды, имена файлов, пути, код или сообщения об ошибках. Англоязычные названия лекций сохраняй как названия первоисточников.

Проверяй не только основные абзацы, но и заголовки, таблицы, задания, учебные запросы к ChatGPT и комментарии внутри примеров.

Если меняется порядок занятий или список программ, заново проверь все зависимости.
