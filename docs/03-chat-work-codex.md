# 3. Chat, Work и Codex

> Проверено: **2026-10-07**. Названия и ограничения использования могут меняться; первичные ссылки даны ниже.

## Перед началом

Приложение ChatGPT для Mac установлено, вход в учётную запись выполнен.

## Сначала научись выбирать режим

| Задача | Режим |
|---|---|
| объяснить, перевести, обсудить, проверить понимание | **Chat** |
| выполнить многоэтапную работу и получить готовый результат | **Work** |
| работать с локальными папками, файлами, Terminal, Git или техническим проектом | **Codex** |

В приложении для Mac выбери **ChatGPT** или **Codex** в верхней левой части окна. В ChatGPT переключайся между режимами **Chat / Work**.

Текущая справка:
<https://help.openai.com/en/articles/20001275-chatgpt-work-and-codex>

## Как экономно расходовать лимит

Если задачу можно решить разговором — используй **Chat**.

Не открывай Codex только чтобы спросить “что означает `git clone`?”. Для объяснения Chat проще и обычно экономнее.

## Выбор модели в Work и Codex

Если эти варианты доступны в твоей учётной записи, используй следующие рекомендации:

1. **GPT-6.1 Sol — Medium**: обычно выбирай этот вариант.
2. **GPT-6.1 Sol — XHigh**: сложная задача, где качество важнее расхода.
3. **GPT-6 Astra — Low/Medium**: запасной вариант для особенно трудных задач, когда Sol не справляется.

Не повышай уровень рассуждений (reasoning effort) без необходимости.

Актуальная справка:
<https://help.openai.com/en/articles/20001516-managing-usage-with-gpt-6-astra-in-work-and-codex>

## Ограничения использования

Лимит нельзя свести к фиксированному числу запросов. Расход зависит от выбранной модели, уровня рассуждений, объёма контекста и продолжительности работы агента.

Проверяй:

- официальный счётчик использования в ChatGPT;
- CodexBar в строке меню macOS;
- если позже начнёшь пользоваться Codex в командной строке — `/status`.

Справка об ограничениях Codex:
<https://help.openai.com/en/articles/11369540-using-codex-with-your-chatgpt-plan>

## CodexBar

Ты установил его в уроке 2. Открой CodexBar из папки Applications, подтверди запуск, если macOS попросит, и оставь значок программы в строке меню.

CodexBar удобен для наблюдения за лимитами. Если его показания расходятся с официальным счётчиком, ориентируйся на данные OpenAI.

Проект:
<https://github.com/steipete/CodexBar>

## Первый запрос к учебному помощнику

`$teach-me` пока **не установлен**. Пока используй обычный запрос:

```text
Я не программист. Объясняй по-русски. Важные английские технические термины при первом упоминании добавляй в скобках.
Не делай практическое упражнение полностью за меня.
Сначала объясни цель, затем дай один следующий шаг.
```

В уроке 8 мы превратим такой запрос в отдельный повторно используемый навык Codex.

## Мини-упражнение

Определи режим:

1. “Переведи и объясни абзац лекции.”
2. «Исследуй пять судоходных компаний и подготовь сравнение со ссылками на источники».
3. «Поработай с файлами в моей папке для упражнений и покажи изменения».

Ответ: **Chat → Work → Codex**.

## Проверка результата

Ты должен уметь открыть каждый из трёх режимов и своими словами объяснить, зачем нужен каждый.
