# 5. Terminal и установка через Homebrew

**Время:** 65–80 минут плюс загрузка. **Результат:** ты настроишь удобное окно Terminal, найдёшь знакомые файлы командами и установишь Git для следующего технического занятия.

## Перед началом

Завершён базовый маршрут до урока 4б; ты выбрал техническое продолжение. В `~/University/Projects/Codex-Practice` есть `one.txt` и `two.txt`. Для установки нужны подходящий Mac, интернет и разрешение на установку программ.

## 1. Открой Terminal и найди знакомую папку

Нажми **Command+Space**, введи `Terminal`, нажми Enter. Terminal — окно для текстовых команд; **командная оболочка (shell)** выполняет их. На современных Mac обычно используется zsh. В примерах копируй только команды, без приглашения вроде `%` или `$`.

### Сначала сделай окно удобным {#appearance}

Отведи пять минут на оформление: крупный текст легче читать, а в широком окне длинные команды реже переносятся на следующую строку. Начнём с профиля **Homebrew**, шрифта **16 пунктов** и окна **120 столбцов × 40 строк**. Это размер в символах и строках текста, не в пикселях.

**Профиль** — сохранённый набор настроек окна: цвета, шрифт и размер. Встроенный профиль Terminal **Homebrew** и менеджер пакетов **Homebrew**, который установим в шаге 4, — разные вещи с одинаковым названием. Для оформления ничего устанавливать не нужно.

1. В верхнем меню выбери **Terminal → Settings / «Терминал → Настройки»**, затем **Profiles / «Профили»**. В старых версиях macOS настройки могут называться **Preferences**.
2. В списке слева выбери **Homebrew**. Нажми **Default / «По умолчанию»** под списком: рядом с этим профилем появится соответствующая отметка.
3. Справа открой **Text / «Текст»**. В разделе **Font / «Шрифт»** нажми **Change / «Изменить»**. Оставь выбранный шрифт и увеличь его размер до **16**. Закрой окно выбора шрифта.
4. В том же профиле открой **Window / «Окно»**. В разделе **Window Size / «Размер окна»** задай **Columns / «Столбцы»: 120**, **Rows / «Строки»: 40**. В разделе **Title / «Заголовок»** включи **Dimensions / «Размеры»**, чтобы видеть фактический размер в заголовке окна.
5. Перейди в общую вкладку **General / «Основные»**. У **On startup, open / «При запуске открывать»** выбери **New window with profile / «Новое окно с профилем» → Homebrew**. Профиль при запуске задаётся отдельно от профиля по умолчанию.
6. Там же для **New windows open with / «Новые окна открываются с»** выбери **Default Profile / «Профиль по умолчанию»**. Для **New tabs open with / «Новые вкладки открываются с»** тоже выбери **Default Profile**. Настройки рабочей папки оставь прежними.
7. Закрой настройки и нажми **Command+N**. Проверь оформление, крупный текст и размер нового окна по его заголовку. Продолжай урок в этом окне: уже открытое окно другого профиля может сохранить прежний вид.

Если окно с таким шрифтом не помещается на экран, уменьши число строк или столбцов в профиле и открой новое окно. Можно попробовать размер шрифта 14–16 пунктов; выбирай тот, который читается без напряжения. При изменении размера мышью число столбцов и строк тоже меняется. В следующий обычный запуск Terminal проверь, что выбран Homebrew; восстановленные старые окна могут сохранять прежнее оформление.

**Проверено по документации Apple: 2026-10-07.** [Профиль при запуске и по умолчанию](https://support.apple.com/guide/terminal/default-startup-terminal-window-profiles-trml5856b1f2/mac), [шрифт](https://support.apple.com/guide/terminal/change-profiles-text-settings-trmltxt/mac), [размер окна](https://support.apple.com/guide/terminal/change-profiles-window-settings-trmlwindw/mac), [настройки новых окон и вкладок](https://support.apple.com/guide/terminal/change-general-settings-trmlstrtup/mac).

### Теперь найди папку командами

Выполняй **по одной строке**, нажимая Enter после каждой:

```bash
cd ~
pwd
ls
```

`cd ~` переводит в домашнюю папку, `pwd` показывает текущий путь, `ls` — содержимое. Среди папок должна быть `University`. Порядок и число колонок вывода `ls` могут отличаться.

```bash
cd ~/University/Projects/Codex-Practice
pwd
ls
open .
```

Ожидаемый путь заканчивается на `/University/Projects/Codex-Practice`; Finder откроет эту же папку. **Текущая папка**, или рабочая директория, — папка, относительно которой выполняется команда. `.` означает её, а `..` — родительскую папку.

## 2. Прочитай файл и создай папку

```bash
cat one.txt
mkdir archive
ls
```

`cat` показывает текст файла; ты должен увидеть `Моя первая учебная заметка.` Команда `mkdir` создаёт папку. Если `archive` уже существует, сообщение `File exists` означает, что повторно создавать её не нужно.

Команда состоит из имени и **аргументов** — уточнений после пробелов. В `cat one.txt` имя файла — аргумент. Для пути с пробелами нужны кавычки, например `cd "папка с пробелами"`; этот пример пока не запускай.

Попробуй клавишу **↑**, чтобы вернуть предыдущую команду, и **Tab**, чтобы дописать начало имени файла. Не нажимай Enter, если вернулась другая команда.

## 3. Научись выходить и замечать ошибки

- **Control+C** прерывает выполняющуюся команду или отменяет незавершённый ввод.
- В просмотрщике справки `man` клавиша **q** возвращает приглашение командной строки.
- `No such file or directory` обычно означает неверный путь или имя.
- `command not found` означает, что оболочка не нашла программу.
- Многие успешные команды, например `cd`, ничего не печатают. Проверяй результат через `pwd`, `ls` или Finder.

Выполни `cat missing-file.txt`. Здесь ошибка ожидаема: такого учебного файла нет. Затем прочитай существующий `one.txt`. Это упражнение на исправление имени, а не повод переустанавливать программу.

## 4. Установи Homebrew

**Homebrew** — программа для установки и обновления других программ из Terminal. Мы используем её для Git и позже Python.

**Проверено: 2026-10-07.** В [требованиях Homebrew](https://docs.brew.sh/Installation) основной поддерживаемый вариант — Apple Silicon и macOS 15 или новее; Intel относится к ограниченному уровню поддержки. Сверь текущие требования со своим Mac. Если компьютер не подходит или установка запрещена, продолжай браузерные задания и запроси помощь с техническим маршрутом; не меняй систему наугад.

1. Проверь `brew --version`. Если уже появился номер версии, пропусти установку.
2. Если Homebrew отсутствует, открой <https://brew.sh/> и скопируй команду установки именно оттуда. Она загружает и запускает официальный установщик; прочитай его сообщение о предстоящих изменениях.
3. Вставь команду в Terminal. При запросе пароля вводи пароль входа на Mac. **Символы и звёздочки не появляются — это нормально.** Нажми Enter. Не отправляй пароль в ChatGPT.
4. При необходимости следуй предложению установить Apple Command Line Tools и дождись завершения.
5. Выполни команды из раздела **Next steps** в конце установки. Они настраивают `PATH` — список мест, где оболочка ищет программы. Не копируй чужой путь из снимка экрана.
6. Проверь ещё раз:

```bash
brew --version
```

Если программа всё ещё не найдена, открой новое окно Terminal и повтори проверку. Затем используй [помощь](help.md).

## 5. Установи инструменты для Git-урока

```bash
brew install git gh
```

`git` будет хранить версии файлов, `gh` поможет войти в GitHub и создать репозиторий. Проверка:

```bash
git --version
gh --version
```

Обновлять и удалять программы научимся в [обслуживании Mac](11-maintenance.md). Mole, CodexBar, DeepL и GitHub Desktop для основного маршрута не обязательны.
