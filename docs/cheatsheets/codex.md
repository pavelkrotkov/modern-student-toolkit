# Шпаргалка: Codex

## Выбор режима

- объяснить, перевести или проверить знания → **Chat**;
- провести большое исследование и получить готовый результат → **Work**;
- работать с локальными файлами, Terminal, Git и техническими задачами → **Codex**.

## Какую модель выбрать

Если доступны:

1. GPT-6.1 Sol Medium — обычный выбор;
2. Sol XHigh — сложная задача;
3. Astra Low/Medium — запасной вариант.

Проверяй актуальность:
<https://help.openai.com/en/articles/20001275-chatgpt-work-and-codex>

## Область доступа к папкам

Открывай только ту папку, которая нужна для задачи.

Перед изменениями:

```text
Пока ничего не меняй.
Покажи, какие файлы видишь, и объясни, что собираешься изменить.
```

## `$teach-me`

Работает после установки в уроке 8:

```text
$teach-me <задача>
```

Если навык ещё не установлен, используй обычный обучающий запрос:

```text
Я хочу научиться, а не получить готовый ответ.
Сначала объясни цель и дай только первый шаг.
```

## Лимиты

Официальный счётчик расхода лимита в твоей учётной записи — главный источник. CodexBar позволяет следить за лимитом через строку меню.

Команда `/status` нужна только при использовании Codex из командной строки. Для прохождения курса она не требуется.
