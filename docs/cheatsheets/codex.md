# Шпаргалка: работа с ИИ

## Выбор способа работы

- Объяснение, обсуждение и подсказки — Chat.
- Готовый результат из нескольких действий — Work, если доступен.
- Код, команды и подробный просмотр технической работы — Codex, если доступен.

Work также может работать с файлами. Возможности зависят от учётной записи и платформы. Начинай с обычных доступных настроек; точная модель не является условием упражнения. [Текущая справка](https://learn.chatgpt.com/docs/use-chatgpt).

## Хорошая постановка задачи

```text
Цель: <что нужно получить>.
Материалы: <прикреплённые файлы или скопированный текст>.
Результат: <имя файла, формат, объём>.
Ограничения: <что можно изменять>.
Проверка: <какие числа, факты или действия подтверждают успех>.
```

Замени заготовки своими сведениями. Убедись, что агент действительно получил материалы; одной ссылки может быть недостаточно.

## Перед изменением файлов

```text
Пока ничего не меняй. Назови выбранную папку и файлы, которые видишь.
Объясни предполагаемые изменения и способ проверки результата.
```

После выполнения открой результат сам, проверь числа и источники, сравни исходные файлы. Разрешение на папку и управление приложениями через Computer Use имеют разные границы доступа.

## Для обучения

```text
Дай одну подсказку и дождись моей попытки.
Затем предложи похожую задачу без помощи ИИ.
```

После дополнительного занятия это можно вызывать как `$teach-me` в Codex. [Установка навыка](../08-skills.md).

## Если что-то пошло не так

Останови задачу, выясни, что уже изменилось, сохрани сообщение об ошибке без секретов. [Помощь](../help.md). При исчерпании лимита продолжай самостоятельную часть или вернись позже; дополнительная покупка не требуется для курса.
