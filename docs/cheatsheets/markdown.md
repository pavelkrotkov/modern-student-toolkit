# Шпаргалка: Markdown

Используй после [подурока 3а](../07a-markdown.md). Markdown — обычный текст с простыми знаками оформления. Имя файла обычно оканчивается на `.md`.

## Самое нужное

| Что нужно | Напиши в файле | Как прочитает редактор |
|---|---|---|
| Главный заголовок | `# Тема` | Заголовок первого уровня |
| Подзаголовок | `## Раздел` | Заголовок второго уровня |
| Жирное выделение | `**важно**` | **важно** |
| Курсив | `*термин*` | *термин* |
| Пункт списка | `- Первый пункт` | Маркированный список |
| Нумерованный список | `1. Первый шаг` | Нумерация |
| Ссылка | `[MIT](https://missing.csail.mit.edu/)` | [MIT](https://missing.csail.mit.edu/) |
| Цитата | `> Фрагмент` | Отдельный блок цитаты |
| Имя файла или команда | `` `notes.md` `` | `notes.md` без изменения знаков |
| Разделитель | `---` на отдельной строке | Горизонтальная черта |

Ставь **пробел после `#`** и оставляй пустую строку между абзацами. Для обычного текста не нужно особое оформление.

## Несколько строк сразу

Чтобы показать код без изменения его символов, поставь по три обратные кавычки до и после блока:

````markdown
```python
print("Привет")
```
````

## Удобные расширения

Некоторые возможности поддерживаются в Obsidian и GitHub, но не входят в базовый CommonMark. В другом приложении проверь их отображение.

| Приём | Пример | Для чего |
|---|---|---|
| Список задач | `- [ ] Проверить` / `- [x] Готово` | Отметка выполнения |
| Таблица | См. образец ниже | Небольшие таблицы |
| Внутренняя ссылка Obsidian | `[[MIT-intro]]` | Переход к другой заметке в хранилище; не универсальный Markdown |
| Зачёркивание | `~~устарело~~` | Пометка исправления |

```markdown
| Вопрос | Ответ |
|---|---|
| Кто автор? | Указать источник |
| Проверено? | Да |
```

**Важно:** `**важно**` хранится именно с символами `*`, пока редактор не покажет оформление. Не всё, что умеют Word или Google Docs (цвета, шрифты, сложная вёрстка), переносится в `.md`.

Для практики: [10-минутный учебник CommonMark](https://commonmark.org/help/tutorial/) и [справочник CommonMark](https://commonmark.org/help/). Расширения Markdown описывает [GitHub](https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax).
