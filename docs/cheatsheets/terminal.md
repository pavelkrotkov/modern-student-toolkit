# Шпаргалка: Terminal

```bash
pwd                  # где я сейчас
ls                   # что здесь есть
ls -la               # включая hidden files
cd FOLDER             # перейти в папку
cd ..                 # на уровень выше
cd ~                  # домой
mkdir NAME            # создать папку
open .                # текущую папку в Finder
cat FILE              # показать текстовый файл
rg "text" PATH        # найти text в файлах
```

Если не понимаешь команду:

```bash
man COMMAND
COMMAND --help
```

Никогда не запускай неизвестную destructive command только потому, что её предложил форум или AI.
