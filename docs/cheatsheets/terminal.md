# Шпаргалка: Terminal

Используй после [урока 5](../02-homebrew.md). Выполняй команды по одной строке. Слова `ПАПКА` и `ФАЙЛ` ниже замени настоящим именем; не копируй их буквально.

| Команда | Что делает |
|---|---|
| `pwd` | Показывает текущую папку |
| `ls` | Показывает её содержимое |
| `ls -a` | Показывает также скрытые имена |
| `cd ~/University` | Переходит в учебную папку |
| `cd ..` | Переходит к родительской папке |
| `cd ~` | Переходит домой |
| `mkdir ПАПКА` | Создаёт папку |
| `open .` | Открывает текущую папку в Finder |
| `cat ФАЙЛ` | Показывает простой текстовый файл |

Путь с пробелами заключай в кавычки: `cat "моя заметка.txt"`. Это сработает, только если файл существует в текущей папке.

**Tab** дописывает имя, **↑** возвращает прежнюю команду, **Control+C** прерывает выполнение. В справке `man` и просмотрщике Git **q** означает выход. Успешная команда не всегда печатает ответ: проверяй через Finder или `pwd` и `ls`.

**Копировать файл:** `cp -i ИСТОЧНИК НАЗНАЧЕНИЕ`. `-i` спрашивает перед заменой; ответ `n` отменяет замену. `>` в командах записи перезаписывает содержимое указанного файла.
