# Шпаргалка: Terminal

```bash
pwd                  # где я сейчас
ls                   # что здесь есть
ls -la               # включая скрытые файлы
cd FOLDER             # перейти в папку
cd ..                 # на уровень выше
cd ~                  # домой
mkdir NAME            # создать папку
open .                # текущую папку в Finder
cat FILE              # показать текстовый файл
rg "text" PATH        # найти text в файлах
```

Если не понимаешь команду:

```bash
man COMMAND
COMMAND --help
```

Не запускай незнакомую команду, которая может удалить или изменить файлы, только потому, что её предложил форум или ИИ.
