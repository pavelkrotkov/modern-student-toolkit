# 11. Поддержание Mac в порядке

## Перед началом

К этому моменту ты уже регулярно пользуешься Homebrew и основными приложениями. Этот урок посвящён обычному обслуживанию Mac, а не ежедневной «оптимизации».

## Раз в месяц

```bash
brew update
brew outdated
brew upgrade
brew cleanup
```

Если хочешь свериться с образцом `Brewfile` из курса, укажи **полный путь к файлу**, не полагаясь на текущую папку Terminal:

```bash
brew bundle check --file ~/University/Projects/modern-student-toolkit/Brewfile
```

Если ты давно не обновлял локальную копию курса, сначала выполни:

```bash
cd ~/University/Projects/modern-student-toolkit
git pull
```

Необязательно устанавливать через `brew bundle` всё из образца: в курсе мы намеренно добавляли программы постепенно.

## Если заканчивается место

Сначала:

```bash
mo analyze
```

Перед очисткой:

```bash
mo clean --dry-run
```

И только после просмотра решай, нужен ли:

```bash
mo clean
```

Mole:
<https://github.com/tw93/Mole>

## Периодически

- устанавливай обновления безопасности macOS;
- проверяй, что резервное копирование действительно выполняется;
- посмотреть свободное место;
- удаляй приложения, которыми больше не пользуешься;
- не устанавливай сразу несколько утилит для «очистки Mac».

Если есть внешний диск, настрой Time Machine и иногда проверяй дату последнего успешного резервного копирования.

## Если Homebrew ведёт себя странно

```bash
brew doctor
```

Прочитай вывод команды. Если непонятно — отправь его целиком в ChatGPT, а не запускай случайные решения с форумов.

## Расход лимита Codex

Перед длительной задачей в Work или Codex проверь официальный счётчик расхода лимита и CodexBar. Если недельный лимит почти исчерпан, используй агента только для задач, где действительно нужна работа с файлами или инструментами. Объяснения получай в Chat.

## Итоговая привычка

Хороший Mac обычно требует меньше “чистки”, чем кажется. Обычный порядок действий:

**обновления → резервное копирование → проверка свободного места → удаление действительно ненужного**.
