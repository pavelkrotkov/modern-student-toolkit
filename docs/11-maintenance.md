# Дополнительно. Резервные копии и обслуживание Mac

**Время:** 20–30 минут активной работы; первое копирование может идти дольше. **Результат:** понятный способ восстановить файл и короткий порядок обслуживания.

## Перед началом

Раздел о резервных копиях доступен после урока 1. Для команд Homebrew нужен урок 5. Для Mole — установленный Homebrew и понимание того, какие файлы можно потерять при очистке. Очистка не обязательна для прохождения курса.

## 1. Сначала восстановление {#backup}

**Проверено: 2026-10-07.** Если есть подходящий внешний диск, настрой Time Machine по [инструкции Apple](https://support.apple.com/guide/mac-help/back-up-files-mh35860/mac): **System Settings → General → Time Machine → Add Backup Disk**. Если macOS предлагает стереть или переформатировать диск с нужными данными, остановись; выбери другой диск или получи помощь владельца данных.

Дождись успешного копирования и проверь его дату. Сохрани новый тестовый файл в `University/Scratch`; дождись копии, измени его содержимое и затем попробуй восстановить прежнюю версию через Time Machine. Используй только этот тестовый файл. [Восстановление файлов](https://support.apple.com/guide/mac-help/restore-files-mh11422/mac).

Если диска нет, запиши, где пока находится независимая копия важных работ и как её открыть. Уточни семейный или университетский способ резервного копирования. Копия в соседней папке на том же Mac не защитит от потери компьютера.

Облачная синхронизация переносит изменения, иногда вместе с ошибками и удалениями. Git хранит выбранные версии. Time Machine копирует файлы по расписанию. Эти способы решают разные задачи.

## 2. Обновления

Периодически проверяй обновления безопасности macOS и самих приложений. Перед большим обновлением убедись, что резервная копия доступна.

Для установленных через Homebrew инструментов:

```bash
brew update
brew outdated
```

Первая команда обновляет сведения о доступных версиях; вторая показывает устаревшее. Посмотри список, затем при необходимости:

```bash
brew upgrade
```

Это обновляет установленные через Homebrew пакеты. Некоторые графические приложения обновляются самостоятельно. При проблеме сохрани точное сообщение; `brew doctor` помогает собрать сведения, но каждое его предупреждение не требует немедленного исправления.

Обычная очистка старых загрузок Homebrew:

```bash
brew cleanup --dry-run
```

После просмотра списка можно выполнить `brew cleanup`, чтобы удалить перечисленные ненужные копии. [Справка Homebrew](https://docs.brew.sh/Manpage).

## 3. Если мало места

Сначала открой **System Settings → General → Storage**. Посмотри, какая категория занимает место. Разбирай знакомые загрузки и дубликаты; важные данные сначала скопируй и проверь копию.

**Mole — дополнительный инструмент**, устанавливать его заранее не нужно. Если решил пользоваться им:

```bash
brew install mole
mo analyze
```

Анализатор показывает занятое место, но его интерфейс также позволяет перемещать выбранные элементы в Корзину после подтверждения. Не подтверждай удаление, если не понимаешь, какие файлы выбраны.

Перед очисткой обязательно:

```bash
mo clean --dry-run
```

Этот запуск показывает предполагаемые удаления. Если список непонятен, остановись. Только после проверки резервной копии и каждого нужного пункта можно отдельно выполнить `mo clean`. Очистка может затронуть Корзину; не рассчитывай на неё как на единственный способ возврата.

[Документация Mole](https://github.com/tw93/Mole).

## 4. Образец набора программ

После клонирования курса можно посмотреть `Brewfile` командой `cat` с полным путём. Он описывает инструменты основного технического маршрута. Установленные вручную приложения могут не учитываться Homebrew так же, как установленные им.

```bash
brew bundle check --verbose --file ~/University/Projects/modern-student-toolkit/Brewfile
```

Команда проверяет соответствие образцу. Сообщение о недостающей программе ожидаемо, если ты ещё не дошёл до её урока или установил её другим способом. Не устанавливай всё автоматически ради зелёной проверки. [Homebrew Bundle](https://docs.brew.sh/Brew-Bundle-and-Brewfile).
