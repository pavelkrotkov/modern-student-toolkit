# Дополнительно. Сохрани учебный запрос как `$teach-me`

**Время:** 20–30 минут. **Результат:** один повторно используемый учебный помощник.

## Перед началом

Ты прошёл уроки 5–8, умеешь работать с путями и уже пользовался Codex с локальной папкой. Репозиторий курса находится в `~/University/Projects/modern-student-toolkit`. Если Codex недоступен, продолжай использовать запрос из урока 2; установка навыка не нужна для основного маршрута.

**Навык (skill)** — папка с файлом `SKILL.md`, где записаны инструкции для повторяющейся задачи. Учебный навык просит давать подсказки и проверять понимание.

## 1. Прочитай перед установкой

```bash
cat ~/University/Projects/modern-student-toolkit/skills/teach-me/SKILL.md
```

Найди правила об одной подсказке, самостоятельном действии и проверке результата. Инструкции навыка помогают задавать поведение, но не гарантируют безошибочную работу ИИ.

## 2. Установи личный навык

**Проверено: 2026-10-07.** Актуальная документация указывает `~/.agents/skills` для личных навыков: [Build skills](https://learn.chatgpt.com/docs/build-skills).

Это папка настроек агента в домашней папке, **вне учебных работ `University`**. Установка осознанно делает навык доступным в разных проектах. Исходный файл останется в репозитории курса.

```bash
mkdir -p ~/.agents/skills/teach-me
ls -la ~/.agents/skills/teach-me
```

Если там уже есть `SKILL.md`, сначала прочитай его; не заменяй существующий навык вслепую. Для новой установки выполни одной строкой:

```bash
cp -i ~/University/Projects/modern-student-toolkit/skills/teach-me/SKILL.md ~/.agents/skills/teach-me/SKILL.md
```

`cp` копирует файл. Параметр `-i` спрашивает перед заменой существующего файла; если не собирался заменять, ответь `n` и Enter.

```bash
cat ~/.agents/skills/teach-me/SKILL.md
```

Проверь, что это тот же текст. Начни новый чат Codex. Если навык не появился в списке, перезапусти приложение.

## 3. Проверь на другой папке

Открой в Codex `~/University/Projects/Codex-Practice` и напиши:

```text
$teach-me Помоги понять разницу между git diff и git diff --staged.
Дай одно упражнение на моём учебном файле. Пока ничего не изменяй.
```

Если интерфейс предлагает список навыков, выбери `teach-me` из него. В ChatGPT Work навыки могут выбираться через `@`; следуй списку доступных навыков в своём интерфейсе.

Ожидай вопроса или первого небольшого шага. Если агент сразу выполнил всё, останови его и попроси дать тебе самостоятельную попытку. Если навык не обнаружен, используй обычный учебный запрос и [помощь](help.md).

## Проверка результата

- [ ] Навык доступен в `Codex-Practice`, а не только в папке курса.
- [ ] Помощник предлагает подсказку и ждёт моей попытки.
- [ ] Я всё равно самостоятельно проверяю объяснения и команды.

**Попробуй сам:** сформулируй с помощью навыка вопрос по одному фрагменту `budget.py` и объясни ответ своими словами.

**Завтра:** используй сохранённый запрос только там, где действительно нужен повторяющийся способ обучения.

Собственные навыки стоит создавать после нескольких удачных повторений одной задачи. Для этого в Codex есть `$skill-creator`; отдельная коллекция навыков не является целью курса.
