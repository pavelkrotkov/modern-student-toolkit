# Современный набор навыков студента

Этот курс не превращает тебя в программиста. Цель другая: **не быть беспомощным перед компьютером и AI-агентами**.

После курса ты должен уметь:

- понимать, где находятся твои файлы и что происходит с ними;
- пользоваться Terminal без страха;
- устанавливать и обновлять программы через Homebrew;
- понимать разницу между Chat, Work и Codex;
- давать Codex доступ к нужной папке, а не ко всему компьютеру;
- понимать, когда нужны файлы/Terminal, browser use или Computer Use;
- пользоваться Git и GitHub как системой истории и синхронизации;
- хранить университетские заметки в Obsidian и private GitHub repo;
- применять готовые AI skills и `$teach-me`;
- читать простейший Python и просить Codex написать полезную автоматизацию;
- работать с источниками через Zotero и документами через ONLYOFFICE;
- проходить MIT Missing Semester даже если английский пока ограничивает скорость.

!!! note "Для кого"
    Курс рассчитан на умного студента без опыта разработки. Команды нужны для понимания и практики, а не для зубрёжки.

## Как проходить

Не надо садиться на восемь часов. Лучше 30–60 минут несколько раз в неделю.

1. **Прочитай короткий урок.**
2. **Сделай действие на своём Mac.**
3. Если непонятно — попроси Chat объяснить по-русски.
4. Если это практическая задача с файлами или Terminal — открой нужную папку в Codex и используй `$teach-me`.
5. В конце сделай маленькое действие без AI.

## Главный принцип

> AI должен увеличивать твою способность что-то делать, а не заменять понимание того, что произошло.

Быстро меняющиеся разделы (модели ChatGPT/Codex, лимиты, названия приложений) отмечены датой проверки и ссылаются на первичную документацию.
