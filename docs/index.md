# Современный набор навыков студента

Этот курс не превращает тебя в программиста. Цель другая: **уметь самостоятельно работать с современным компьютером и AI-инструментами, даже если рядом нет технического человека**.

!!! important "Начни с сайта и иди по порядку"
    В начале курса **не нужно скачивать этот GitHub repository** и не нужно знать Git. Ты читаешь сайт в browser. Сам repository мы специально скачаем позже, в Git-уроке, когда уже будет понятно, что означает `git clone`.

## После курса ты должен уметь

- понимать, где находятся твои файлы;
- пользоваться Finder и базовыми командами Terminal;
- устанавливать и обновлять программы через Homebrew;
- понимать разницу между Chat, Work и Codex;
- открывать в Codex только нужную папку;
- понимать, когда нужны direct files/Terminal, browser или Computer Use;
- понимать repository, clone, commit, diff, push и pull;
- хранить университетские заметки в Obsidian и отдельном private GitHub repo;
- установить и использовать `$teach-me`;
- читать простейший Python и обсуждать небольшую автоматизацию с Codex;
- работать с Zotero, ONLYOFFICE и переводом;
- использовать MIT Missing Semester как практический учебник.

## Постоянная структура папок

Весь курс использует одну структуру:

```text
~/University/
├── Notes/       # Obsidian vault и только заметки
├── Projects/    # course repo, Git projects, Python experiments
├── Sources/     # PDFs, datasets, исходные материалы
└── Scratch/     # временные эксперименты
```

Не меняй эти роли папок по ходу курса: так команды в следующих уроках будут совпадать с твоим Mac.

## Как проходить

Лучше 30–60 минут несколько раз в неделю.

1. Прочитай **«Перед началом»**.
2. Выполни действия ровно по порядку.
3. После команды посмотри на результат, а не просто переходи к следующей.
4. Если застрял — открой [«Если застрял»](help.md).
5. В конце урока выполни checkpoint. Если он не проходит, не переходи дальше.

До урока 8 мы используем обычные prompts для обучения. `$teach-me` появляется только после того, как ты научишься клонировать repo и установишь skill.

## Главный принцип

> AI должен увеличивать твою способность что-то делать, а не скрывать от тебя, что произошло.

Быстро меняющиеся разделы (OpenAI models, limits, UI) отмечены датой проверки и ссылаются на первичную документацию.
