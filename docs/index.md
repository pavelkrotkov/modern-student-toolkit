# Современный набор навыков студента

Этот курс не превращает тебя в программиста. Цель другая: **уметь самостоятельно работать с современным компьютером и инструментами искусственного интеллекта (ИИ), даже если рядом нет технического человека**.

!!! important "Начни с сайта и иди по порядку"
    В начале курса **не нужно скачивать этот репозиторий с GitHub** и не нужно знать Git. Ты читаешь сайт в браузере. Сам репозиторий мы специально скачаем позже, на уроке Git, когда уже будет понятно, что означает `git clone`.

## После курса ты должен уметь

- понимать, где находятся твои файлы;
- пользоваться Finder и базовыми командами Terminal;
- устанавливать и обновлять программы через Homebrew;
- понимать разницу между Chat, Work и Codex;
- открывать в Codex только нужную папку;
- понимать, когда лучше работать с файлами и Terminal, когда использовать браузер, а когда — управление компьютером (Computer Use);
- понимать, что такое репозиторий, клонирование, сохранение изменений и синхронизация с GitHub;
- хранить университетские заметки в Obsidian и отдельном закрытом репозитории GitHub;
- установить и использовать `$teach-me`;
- читать простейший Python и обсуждать небольшую автоматизацию с Codex;
- работать с Zotero, ONLYOFFICE и переводом;
- проходить практические занятия курса MIT Missing Semester.

## Постоянная структура папок

Весь курс использует одну структуру:

```text
~/University/
├── Notes/       # хранилище Obsidian и только заметки
├── Projects/    # репозиторий курса, проекты Git, упражнения по Python
├── Sources/     # файлы PDF, наборы данных и другие исходные материалы
└── Scratch/     # временные эксперименты
```

Не меняй назначение папок по ходу курса: так команды в следующих уроках будут соответствовать расположению файлов на твоём Mac.

## Как проходить

Лучше 30–60 минут несколько раз в неделю.

1. Прочитай **«Перед началом»**.
2. Выполни действия ровно по порядку.
3. После команды посмотри на результат, а не просто переходи к следующей.
4. Если застрял — открой [«Если застрял»](help.md).
5. В конце урока проверь результат. Если что-то не получилось, не переходи дальше.

До урока 8 мы используем обычные запросы к ИИ для обучения. `$teach-me` появляется только после того, как ты научишься клонировать репозиторий и установишь навык.

## Главный принцип

> ИИ должен увеличивать твою способность что-то делать, а не скрывать от тебя, что произошло.

Быстро меняющиеся разделы (модели OpenAI, ограничения использования, интерфейс) отмечены датой проверки и ссылаются на первичную документацию.
