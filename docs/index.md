# Современный набор навыков студента

Этот курс поможет самостоятельно учиться и работать на Mac: находить файлы, проверять ответы искусственного интеллекта (ИИ), собирать источники, делать документы и таблицы, понимать небольшие программы.

**Начни с [урока 0](00-start.md).** Курс читают в браузере. Скачивать репозиторий и знать Git заранее не нужно.

!!! note "По желанию: печать без взгляда на клавиатуру"

    Этот навык можно развивать параллельно с курсом. Выбери один бесплатный тренажёр для нужного языка:

    - **Русский:** [TypingStudy — первый урок](https://www.typingstudy.com/ru-russian-3/lesson/1).
    - **Английский:** [Typing.com — уроки](https://www.typing.com/student/lessons).
    - **Испанский:** [Typing.com Español](https://www.typing.com/es/curriculum/espanol).

    Все работают в браузере; установка и оплата не нужны. Начать можно без учётной записи. Для сохранения истории можно зарегистрироваться; в TypingStudy история доступна только после входа.

    1. Занимайся **10–15 минут каждый день** в течение нескольких недель. Начни с первых уроков, следуй подсказкам о положении пальцев и старайся не смотреть на клавиатуру.
    2. Проходи уроки по порядку. Стремись к **точности не ниже 95%** перед переходом дальше; скорость придёт с практикой. Проверь, что раскладка в тренажёре совпадает с выбранной раскладкой на Mac.
    3. Раз в неделю проходи один и тот же тест на набор текста и записывай скорость в словах в минуту (WPM) и точность в своей заметке.

## Два завершённых результата

**Учебная работа:** найти и проверить источники, объяснить своими словами, подготовить документ и таблицу в ONLYOFFICE, исправить ошибку, передать нужную версию и восстановить файл. Этот маршрут заканчивается собственной работой в уроке 4б и **считается полноценным завершением курса**.

**Техническая самостоятельность:** по желанию продолжить с Terminal, установкой программ, агентами, Git и чтением небольшой программы Python. Это ещё один результат, а не условие зачёта первого маршрута.

## Учебная работа

Время — ориентир для первой попытки, без долгих загрузок, обновлений, копирования и ожидания партнёра. Базовый маршрут — примерно **7–10 часов**, техническое продолжение — ещё **5–7 часов**; вместе **12–17 часов**. Новые практики входят в эту оценку. Реальное время начинающего уточним после пробного прохождения. Делить занятия на отрезки по 30 минут нормально; скорость не оценивается.

## Одна структура папок

```text
~/University/
├── Notes/       # твои заметки
├── Projects/    # учебные работы и программы
├── Sources/     # исходные материалы и данные
└── Scratch/     # безопасные опыты на копиях
```

`~` обозначает домашнюю папку твоей учётной записи. Её откроем в уроке 0.

## Как учиться

1. Прочитай «Перед началом» и цель занятия.
2. Выполни разобранный пример; сравни результат с образцом.
3. Сделай «Попробуй сам», закрыв подсказку ИИ. Шпаргалкой пользоваться можно.
4. На следующий день повтори короткую проверку из урока.
5. Если застрял — открой одну [подсказку](hints.md) или [помощь](help.md). Запиши шаг и необходимую помощь в [журнале](progress.md).

Контрольные списки на сайте предназначены для самопроверки. Отмечай выполненное в своей заметке: сайт не сохраняет прогресс.

> Хороший результат — ты можешь проверить работу ИИ и повторить нужное действие самостоятельно.
