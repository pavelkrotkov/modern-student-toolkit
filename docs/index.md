# Современный набор навыков студента

Этот курс поможет самостоятельно учиться и работать на Mac: находить файлы, проверять ответы искусственного интеллекта (ИИ), собирать источники, делать документы и таблицы, понимать небольшие программы.

**Начни с [урока 0](00-start.md).** Курс читают в браузере. Скачивать репозиторий и знать Git заранее не нужно.

## Что получится

В первых занятиях ты подготовишь заметку по источникам и проверенный бюджет учебной поездки. Затем научишься поручать агенту работу с файлами, сохранять версии и повторять расчёт небольшой программой Python. Для упражнений есть готовые материалы с известными ответами.

## Одна структура папок

```text
~/University/
├── Notes/       # твои заметки
├── Projects/    # учебные работы и программы
├── Sources/     # исходные материалы и данные
└── Scratch/     # безопасные опыты на копиях
```

`~` обозначает домашнюю папку твоей учётной записи. Её откроем в уроке 0.

## Как учиться

1. Прочитай «Перед началом» и цель занятия.
2. Выполни разобранный пример; сравни результат с образцом.
3. Сделай «Попробуй сам», закрыв подсказку ИИ. Шпаргалкой пользоваться можно.
4. На следующий день повтори короткую проверку из урока.
5. Если застрял — используй [помощь](help.md). Запиши, какой шаг оказался непонятным.

Контрольные списки на сайте предназначены для самопроверки. Отмечай выполненное в своей заметке: сайт не сохраняет прогресс.

> Хороший результат — ты можешь проверить работу ИИ и повторить нужное действие самостоятельно.
