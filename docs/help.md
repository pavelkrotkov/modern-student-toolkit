# Если застрял

Эта страница нужна потому, что курс должен работать без человека рядом.

## Главное правило

**Не угадывай и не запускай всё подряд.** Ошибка — это информация.

Если команда или интерфейс программы не совпадает с описанием в уроке:

1. остановись;
2. не повторяй команду, которая может удалить или изменить файлы;
3. скопируй точный текст ошибки или сделай снимок экрана;
4. открой ChatGPT;
5. сообщи номер урока и шага.

Пример запроса:

```text
Я прохожу Modern Student Toolkit, урок <номер>, шаг <номер>.
Я на Mac и не программист.
Ожидалось: <что написано в курсе>.
Получилось: <точный текст или снимок экрана>.
Сначала объясни, что произошло. Затем дай только следующий безопасный шаг.
Не предлагай удалять файлы или менять системные настройки без объяснения.
```

## Если Terminal показывает ошибку

Скопируй **команду и весь ответ Terminal**. Не пересказывай ошибку своими словами.

Перед новой попыткой полезно спросить:

```text
Эта команда безопасна для повторного запуска?
Если да, объясни почему.
```

## Если потерялся в папках

В Terminal выполни только:

```bash
pwd
ls
```

Отправь оба результата в ChatGPT и спроси, где ты находишься.

## Если Codex предлагает много изменений

Ответь:

```text
Пока ничего не меняй.
Перечисли файлы, которые собираешься изменить, и объясни цель каждого изменения.
```

## Если урок ссылается на `$teach-me`, но команда не работает

Не пытайся настраивать навык раньше времени. `$teach-me` устанавливается только в **уроке 8**. До него используй обычный запрос к ИИ для обучения из соответствующего урока.

## Когда можно продолжать

Продолжай урок только когда понимаешь:

- где находишься;
- что именно делает следующая команда;
- какой результат примерно ожидаешь.
