# Если застрял

Ошибка помогает понять, какой шаг требует уточнения. Сначала остановись, сохрани текст команды и сообщения, затем выбери подходящий случай ниже.

## Что делать сразу

1. Не повторяй вслепую действие, которое меняет или удаляет файлы.
2. В Terminal нажми **Control+C**, если команда продолжает работать и ты хочешь её остановить. В просмотрщике `man`, `git log` или `git diff` нажми **q**.
3. Проверь место файла в Finder. Если уже дошёл до Terminal, проверь текущую папку через `pwd` и её содержимое через `ls`.
4. Скопируй команду и сообщение. Перед отправкой убери пароли, токены, коды входа и личные данные.

## Частые случаи

| Что видишь | Следующий шаг |
|---|---|
| Пароль вводится, но символов нет | Для запроса пароля Terminal это нормально; введи пароль Mac и нажми Enter |
| `command not found` | Проверь имя программы и её установку в нужном уроке; для Homebrew проверь `Next steps` |
| `No such file or directory` | Выполни `pwd`, `ls`, сравни имя, расширение и путь |
| `File exists` | Посмотри, что уже существует; не удаляй прежнюю работу ради повторения шага |
| `Author identity unknown` | Вернись к настройке имени и почты в уроке 7 |
| `git diff` пуст, хотя файл новый | Посмотри `git status`; после добавления конкретного файла используй `git diff --staged` |
| Git сообщает о конфликте | Остановись и сохрани сообщение; не применяй `--force` или `reset --hard` наугад |
| CSV открылся одним столбцом | Повтори импорт с разделителем-запятой, UTF-8 и десятичной точкой |
| Формула в таблице не считает | Проверь знак `=` и числовой формат исходных значений; вернись к настройкам импорта |
| Итог правдоподобен, но новая покупка не учтена | Выдели формулу и проверь последнюю строку диапазона; [подсказки](hints.md#spreadsheet) |
| Цена выглядит числом, но расчёт ошибочен | Посмотри само значение в строке формул: там могут быть текст и единицы; исправляй по источнику, не подгоняй итог |
| Партнёр не видит файл или последнюю правку | Сравните учётную запись, права, название и версию; локальная копия и документ DocSpace могут различаться |
| В DocSpace не появилась новая версия | Завершите сеанс редактирования оба, подождите и снова откройте историю |
| Work, Codex или Computer Use отсутствует | Используй обходной вариант соответствующего урока; запиши отложенную часть |
| В Brave не работают вход, оплата или видео | Проверь правильность адреса, выключи Shields **только для этого сайта**, обнови страницу. Если не помогло, попробуй Safari; [подурок 0а](00a-passwords-browser.md) |
| Bitwarden не предлагает пароль для сайта | Проверь адрес сайта в записи, установку расширения или включение системного заполнения; [подурок 0а](00a-passwords-browser.md) |
| `$teach-me` не найден | Навык необязателен; проверь дополнительный урок и используй обычный учебный запрос |

## Запрос к помощнику

```text
Я прохожу Modern Student Toolkit.
Урок и шаг: <номер и название>.
Ссылка на урок: <адрес страницы>.
Моя система и приложение: <версия macOS, название приложения>.
Ожидалось: <результат из урока>.
Получилось: <команда и точное сообщение без секретов>.
Сначала объясни причину, затем предложи один следующий шаг.
Если нужно изменить или удалить файлы, назови их и объясни последствия.
```

Замени заготовки своими сведениями. Если ИИ не может открыть урок, скопируй нужный абзац. Не полагайся на то, что помощник знает содержание курса по названию.

Если задача агента пошла не туда, нажми кнопку остановки. Попроси перечислить уже выполненные изменения, проверь файлы и только затем продолжай. Новое сообщение «ничего не меняй» не отменяет уже выполненные действия.

Если ChatGPT недоступен, проверь таблицу выше и официальную ссылку в уроке. Сохрани вопрос для автора курса; упражнение с незнакомыми изменениями системы можно отложить.

## Как сообщить о трудности {#feedback}

Сохрани в `~/University/Notes/Course-feedback` (заметка Obsidian или простой текст):

```text
Дата:
Урок и шаг:
Версии macOS и приложения, язык интерфейса:
Сколько минут заняло:
Что я хотел сделать:
Что ожидал увидеть:
Что увидел:
Что смог сам / со шпаргалкой / с ИИ:
Что помогло бы в инструкции:
```

Для передачи автору достаточно этого фрагмента и при необходимости снимка экрана без личных данных. Заводить учётную запись GitHub ради обратной связи не нужно.

Короткие результаты и следующее повторение записывай в [личный журнал](progress.md). Если трудно найти нужную кнопку, проверь [справку об интерфейсе](interface-reference.md); если трудно решить задачу — [лестницу подсказок](hints.md).

## Когда продолжать
