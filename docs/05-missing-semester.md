# Дополнительно. MIT Missing Semester по частям

**Время:** 15–30 минут на один фрагмент. **Результат:** ты применишь одну идею MIT в своей учебной папке.

## Перед началом

Для первого фрагмента пройди наш урок 5, для второго — урок 7, для третьего — уроки 6 и 8. Весь курс MIT не является обязательным условием прохождения Modern Student Toolkit.

[MIT Missing Semester 2026](https://missing.csail.mit.edu/2026/) состоит из девяти плотных лекций. Для первого знакомства используй текстовые разделы ниже. Дополнительные команды и программы из соседних разделов пока можно пропускать.

## 1. Пути и текущая папка

Открой [Course Overview + Introduction to the Shell](https://missing.csail.mit.edu/2026/course-shell/). Через Command+F найди заголовок **Navigating in the shell**. Прочитай этот раздел до **What is available in the shell?** и остановись.

В Terminal перейди в `~/University/Projects/Codex-Practice`, выполни `pwd`, затем `cd ..` и снова `pwd`. Предскажи второй путь до команды. Не выполняй примеры MIT с системными каталогами, если пока не понимаешь их назначения.

**Проверка:** второй путь заканчивается на `/University/Projects`. `..` означает родительскую папку. У MIT в примерах может быть Bash и приглашение `$`, а у тебя — zsh и `%`: команды этого упражнения подходят обеим оболочкам.

## 2. Модель истории Git

Открой [Version Control and Git](https://missing.csail.mit.edu/2026/version-control/). Найди раздел **Git’s data model**. Прочитай о снимках и истории до заголовка **Data model, as pseudocode** и остановись; сложные структуры можно оставить на потом.

В своём `Codex-Practice` выполни `git log --oneline`. Выбери один коммит и объясни, какие файлы и зачем ты тогда сохранил. Практика веток и объединения изменений сейчас не требуется.

## 3. Агент и проверка

Открой [Agentic Coding](https://missing.csail.mit.edu/2026/agentic-coding/). Найди заголовок **Use cases**. Прочитай первые два пункта: **Implementing new features** и **Fixing errors**. Остановись перед **Refactoring**. Обрати внимание, зачем проверять сами тесты и давать агенту обратную связь по ошибкам.

Примени идею к `budget.py`: назови входные данные и заранее известный правильный результат. Попроси агента предложить один способ проверки, затем выполни проверку сам. Не устанавливай дополнительные инструменты из лекции ради этого задания.

## Английский без лишней нагрузки

Скопируй выбранный фрагмент в Chat:

```text
Объясни этот фрагмент по-русски. Выдели три главные мысли.
При первом упоминании важных терминов дай английское название в скобках.
Команды и имена файлов сохрани без перевода.
Затем задай один вопрос и дождись моего ответа.
```

Сначала попробуй прочитать короткий фрагмент сам. Перевод — помощь для понимания; утверждения о командах сверяй с оригиналом и своей системой. Отдельный переводчик устанавливать не обязательно.

## Проверка результата

- [ ] Могу объяснить одну новую мысль своими словами.
- [ ] Выполнил одно связанное действие и показал результат.
- [ ] Знаю, на каком разделе остановился.

**Попробуй сам:** выбери другой путь в `University` и повтори упражнение с `..` без ИИ.

**Завтра:** вспомни три термина своего фрагмента до перечитывания.

**Проверено: 2026-10-07.** Если текст MIT изменился и заголовок не находится, ориентируйся на названную тему; не проходи всю лекцию в поисках одного шага. Более подробная вводная практика: [Software Carpentry — The Unix Shell](https://swcarpentry.github.io/shell-novice/).
