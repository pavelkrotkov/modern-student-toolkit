# 1. Mac: находи, сохраняй и восстанавливай файлы

**Время:** 60–90 минут без ожидания копирования. **Результат:** ты создашь текстовый файл и PDF, найдёшь их и восстановишь файл из независимой копии.

## Перед началом

Пройден урок 0; существуют четыре папки внутри `University`. Используем встроенные Finder, TextEdit и Preview. Terminal появится в уроке 5.

## 1. Освой несколько полезных действий

| Действие | Как выполнить |
|---|---|
| Открыть приложение через Spotlight | **Command+Space**, ввести название, Enter |
| Переключиться между приложениями | **Command+Tab** |
| Посмотреть выбранный файл в Finder | **Пробел** — Quick Look; ещё раз Пробел, чтобы закрыть |
| Найти слово на странице | **Command+F** |
| Отменить последнее редактирование | **Command+Z** |
| Сделать снимок области экрана | **Shift+Command+4**, выделить область; Esc отменяет выбор |

Снимок обычно сохраняется на рабочий стол; место можно посмотреть в **Shift+Command+5 → Options**. Перед отправкой проверь, что в кадре нет паролей, кодов входа и чужих личных данных.

Открой два окна: курс в браузере и Finder. Перетащи их за верхнюю часть так, чтобы видеть оба. Не обязательно настраивать специальный режим размещения окон.

## 2. Создай настоящий текстовый файл

1. Открой Finder → **Shift+Command+H** → `University` → `Projects`.
2. Создай папку `Codex-Practice` через **Shift+Command+N**.
3. Открой **TextEdit** через Spotlight. Выбери **New Document / «Новый документ»**, если появился диалог, или **File → New**.
4. Выбери **Format → Make Plain Text / «Формат → Преобразовать в простой текст»**. Если пункт называется `Make Rich Text`, документ уже простой.
5. Напиши: `Моя первая учебная заметка.`
6. Нажми **Command+S**. Назови файл `one.txt`. В диалоге сохранения нажми **Shift+Command+G**, введи `~/University/Projects/Codex-Practice`, нажми Enter, затем **Save / «Сохранить»**.

**Путь** — адрес файла или папки. `~` — домашняя папка; `/` разделяет части адреса. Наш файл находится по пути `~/University/Projects/Codex-Practice/one.txt`.

В Finder включи **Finder → Settings → Advanced → Show all filename extensions**. На русском ищи настройку показа расширений имён файлов. **Расширение** — окончание имени: `.txt` для простого текста, `.pdf` для PDF. Проверь, что файл не называется `one.txt.rtf` или `one.txt.txt`. Переименование `.rtf` в `.txt` не преобразует содержимое: используй TextEdit.

Открой `one.txt` ещё раз и проверь свою строку. [Инструкция Apple для TextEdit](https://support.apple.com/guide/textedit/create-open-and-convert-documents-txtee6663a0e/mac) · [Если окно выглядит иначе](interface-reference.md#textedit).

## 3. Сохрани учебный источник как PDF

1. Открой [условия учебной поездки](practice/trip-brief.md).
2. В браузере нажми **Command+P**. Выбери сохранение в PDF: в Chrome это `Destination → Save as PDF`; в системном диалоге macOS — меню `PDF`.
3. Сохрани файл `trip-brief.pdf` в `~/University/Sources` через **Shift+Command+G** в диалоге сохранения.
4. В Finder выбери файл и нажми Пробел. Проверь, что видны условия поездки, а текст читается.
5. Открой его в Preview / «Просмотр»: щёлкни правой кнопкой → **Open With → Preview**. Попробуй выделить одну фразу инструментом выделения текста и добавить подсветку через панель разметки. Если нужна чистая копия, сначала выбери **File → Duplicate**.

PDF сохраняет вид страницы; редактируемую работу позже сохраним также в `.docx` или `.xlsx`.

## 4. Найди и восстанови файл

1. Открой Spotlight, введи `trip-brief`. Найди PDF и открой его.
2. В Finder вернись к `one.txt`. Нажми **Command+D** — появится копия. Переименуй её в `recovery-practice.txt`: выдели копию, нажми Enter, введи имя, ещё раз Enter.
3. Только эту копию перемести в Корзину через **Command+Delete**.
4. Открой Корзину в Dock, щёлкни по `recovery-practice.txt` правой кнопкой и выбери **Put Back / «Вернуть»**.
5. Проверь, что копия снова находится в `Codex-Practice`.

Корзину в этом упражнении не очищаем. Восстановление из неё — не резервная копия на случай поломки или потери Mac.

## 5. Что делать со скачанным ZIP

ZIP — архив, который хранит несколько файлов вместе. В Finder двойной щелчок обычно распаковывает его в соседнюю папку. Чтобы создать архив, выдели учебную папку → правая кнопка → **Compress / «Сжать»**. Сейчас попробуй это только с `Codex-Practice`; исходная папка останется на месте. Программы из незнакомых архивов не запускай.

## 6. Проверь независимую копию {#recovery}

В TextEdit создай простой файл `restore-check.txt` в `~/University/Scratch`. Напиши `Версия до изменения.` и сохрани. Выбери доступный способ:

- **Time Machine:** дождись копирования этого файла; затем измени его текст. По [инструкции восстановления Apple](https://support.apple.com/guide/mac-help/restore-files-mh11422/mac) верни прежнюю версию только тестового файла. Настройка диска описана в [дополнительном занятии](11-maintenance.md#backup).
- **Внешний накопитель:** скопируй тестовый файл на него и открой копию. Измени исходник на Mac. Скопируй сохранённый файл обратно в новую папку `Scratch/Restored` и проверь прежний текст. Подключать и стирать чужой накопитель не нужно.
- **Разрешённое облачное хранилище:** вручную загрузи тестовый файл через браузер. После изменения локального исходника скачай сохранённую копию в `Scratch/Restored` и открой. Это проверка отдельной копии; автоматическая синхронизация могла бы перенести и ошибочное изменение.

Запиши **место копии, дату и результат восстановления**, без паролей. Если подходящего места пока нет, продолжай упражнения, но оставь проверку незавершённой до конца базового маршрута. Одна удачная попытка не заменяет регулярного копирования важных работ.

??? tip "Не получилось — сначала подсказка"
    Открой сохранённую копию отдельно. Проверь, что она действительно содержит старую строку, а не автоматически обновившуюся версию. Подробные [подсказки](hints.md#files) открывай по одной.

## Проверка результата

- [ ] В `Codex-Practice` открывается `one.txt` с моей строкой.
- [ ] В `Sources` есть читаемый `trip-brief.pdf`.
- [ ] Учебная копия восстановлена из Корзины.
- [ ] Понимаю отличие имени файла, расширения и пути.
- [ ] Нашёл независимую копию и восстановил прежний текст тестового файла — либо явно записал, что ещё предстоит.

**Слова занятия:** путь — адрес файла; расширение — окончание имени, обозначающее формат; восстановление — получение нужного содержимого из сохранённой копии.

Создай в TextEdit `~/University/Notes/Course-progress.txt` и скопируй [короткий шаблон прогресса](progress.md). Заполняй по одной строке после занятия.
