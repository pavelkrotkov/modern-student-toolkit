# Раскладки Mac и печать на разных языках

**Перед началом:** нужны Mac и браузер. Новую клавиатуру покупать не нужно: источник ввода определяет, какие символы появляются при нажатии клавиш, независимо от надписей на них. Язык интерфейса Mac менять не требуется.

## Добавь русский или испанский

1. Открой ** → System Settings / «Системные настройки» → Keyboard / «Клавиатура»**.
2. В разделе **Text Input / «Ввод текста»** рядом с источниками ввода нажми **Edit / «Изменить»**, затем **+**.
3. Найди **Russian / «Русский»** или **Spanish / «Испанский»**, выбери вариант по пояснениям ниже и нажми **Add / «Добавить»**. Сохрани английский источник ввода для английских упражнений.
4. Переключай раскладки через меню ввода справа в строке меню. **Control+пробел** возвращает последний использованный источник, **Control+Option+пробел** выбирает следующий. Если сочетание не работает, используй меню; клавиша `⌘` — это Command, а не Control.

Из меню ввода открой **Show Keyboard Viewer / «Показать панель “Клавиатура”»**. Она показывает реальные позиции символов, в том числе при нажатии **Shift** и **Option**. [Инструкция Apple](https://support.apple.com/ru-ru/guide/mac-help/mchlp1406/mac).

## Какую русскую раскладку выбрать

**Для уроков TypingStudy выбери ЙЦУКЕН.** В Mac доступны **Russian** и **Russian – PC**; вторая ближе к изображённой в [русских уроках](https://www.typingstudy.com/ru-russian-3/lesson/1) клавиатуре ПК. Сверь буквы и знаки с панелью «Клавиатура» перед упражнением. Кириллические надписи на физических клавишах не обязательны: позиции осваиваются по подсказкам тренажёра.

**Если уже печатаешь по-английски и хочешь использовать знакомые позиции, попробуй фонетический вариант.** На проверенном Mac он называется **Russian – QWERTY**, в более старых версиях — **Russian – Phonetic / «Русская — фонетическая»**. Многие буквы находятся на клавишах с похожим звучанием: `A → а`, `S → с`, `D → д`, `F → ф`, `K → к`, `M → м`. После переключения Mac сразу вводит кириллицу; оставаться в английском источнике ввода нельзя.

Это уменьшает число новых позиций, но не устраняет обучение полностью: для **ё, ж, ч, ш, щ, ъ, ь, э, ю, я** нужно посмотреть выбранную раскладку, включая слой Option. [Памятка UC Davis](https://ucdlc.ucdavis.edu/sites/g/files/dgvnsk9431/files/inline-files/russian_phonetic_keyboard_mac.pdf) показывает старое название и пример расположения; актуальную схему смотри на своём Mac.

**Фонетический вариант не совпадает с ЙЦУКЕН в TypingStudy.** Его русские уроки не обучают этой раскладке: подсказки о клавишах и пальцах будут другими. Для этого варианта сначала освой положение пальцев в английских уроках Typing.com, затем ежедневно набирай короткий русский текст в своей заметке, постепенно добавляя незнакомые буквы. Когда позиции станут привычными, используй [русский тест текста](https://www.typingstudy.com/ru-russian-3/typingtest) для проверки скорости и точности, ориентируясь на раскладку Mac, а не на схему сайта.

## Испанский

Добавь **Spanish**; **Latin American** — другой вариант с иным расположением некоторых знаков. Для [Typing.com Español](https://www.typing.com/es/curriculum/espanol) сравни выбранную раскладку со схемой в упражнении, особенно **ñ, ударение ´, ¿ и ¡**. Даже варианты с одинаковым языком могут различаться между Mac и ПК.

Найди эти символы в панели «Клавиатура». Для **á, é, í, ó, ú** в испанской раскладке сначала нажми клавишу ударения **´**, отпусти её, затем нажми гласную: ударение соединится с буквой. Отсутствие испанских надписей на английской клавиатуре не мешает вводу. [Справка Apple о диакритике](https://support.apple.com/ru-ru/guide/mac-help/mh27474/mac).

**Проверка:** в своей заметке набери `Привет, ёж!` и `¡Hola! ¿Qué tal? El niño llegó.` с нужными источниками ввода. Вернись к английскому и набери `Hello`. Если символы отличаются, проверь выбранный источник и панель «Клавиатура».

**Проверено: 2026-10-10.** Путь настройки сверен со справкой Apple; названия доступных раскладок и фонетические соответствия проверены в настройках Mac.
