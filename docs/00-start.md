# 0. Подготовь Mac и учебные папки

**Время:** 20–30 минут. **Результат:** ты знаешь, где будут лежать работы и как получить помощь.

## Перед началом

Нужны Mac, браузер и интернет. Для урока 2 понадобится доступ к ChatGPT через разрешённую тебе учётную запись. Git, Terminal и платная подписка для первого занятия не нужны.

## 1. Сохрани курс

Открой <https://pavelkrotkov.github.io/modern-student-toolkit/>. Нажми **Command+D**, чтобы добавить страницу в закладки браузера. `Command` — клавиша с символом `⌘`.

Открой <https://chatgpt.com/> в соседней вкладке. Если вход пока недоступен, проходи урок 1; в уроке 2 есть упражнение на проверку готового ответа.

## 2. Проверь условия работы

Открой меню ** → About This Mac / «Об этом Mac»**. Запиши модель, процессор и версию macOS. Позже они помогут проверить совместимость программ.

- На учебном или семейном Mac установка приложений может требовать разрешения владельца или администратора. Не обходи ограничения; сначала уточни доступ.
- В **System Settings / «Системные настройки»** проверь вход в учётную запись Apple и настройку **Find My Mac / «Найти Mac»**. Если нужна помощь с семейной учётной записью, обратись к её владельцу.
- Проверь наличие резервной копии. Если Time Machine уже настроен, посмотри дату последнего копирования. [Настройка и восстановление](11-maintenance.md#backup) описаны отдельно. Отсутствие внешнего диска не мешает упражнениям на новых учебных файлах.
- Обновления безопасности находятся в **System Settings → General → Software Update**. Перед большим обновлением системы сначала проверь резервную копию и совместимость нужных учебных программ.

**Проверено: 2026-10-07.** Homebrew, приложения и функции ИИ имеют разные требования. Проверим их непосредственно перед установкой. Возможности Work и Codex зависят от учётной записи, платформы и настроек организации: [справка OpenAI](https://learn.chatgpt.com/docs/use-chatgpt).

## 3. Создай папки

1. Нажми значок Finder в Dock — панели приложений.
2. Нажми **Shift+Command+H**. Откроется домашняя папка твоей учётной записи.
3. Выбери **File → New Folder / «Файл → Новая папка»** или нажми **Shift+Command+N**.
4. Назови папку `University` и нажми Enter. Если такая папка уже есть, открой её; не заменяй её содержимое.
5. Дважды щёлкни по `University`. Тем же способом создай внутри четыре папки:

```text
University/
├── Notes/
├── Projects/
├── Sources/
└── Scratch/
```

Это локальные папки. Создание `University` само по себе не включает облачную синхронизацию или резервное копирование.

## 4. Если интерфейс отличается

Попроси помощника:

```text
Я прохожу Modern Student Toolkit, урок 0, шаг 3.
Я на Mac. Ожидалось: <опиши ожидаемый результат>.
Получилось: <опиши экран или приложи снимок без личных данных>.
Объясни по-русски и предложи один следующий шаг.
```

Текст в угловых скобках замени своим описанием. Снимки экрана научимся делать в уроке 1.

## Проверка результата

- [ ] Открываю курс из закладки.
- [ ] Нахожу `University` через домашнюю папку Finder.
- [ ] Внутри ровно четыре учебные папки, перечисленные выше.
- [ ] Знаю, доступен ли ChatGPT и могу ли устанавливать приложения.

**Попробуй сам:** закрой окно Finder и снова найди `Sources` без подсказки ИИ.

**Завтра:** открой курс из закладки и снова найди `University`.
