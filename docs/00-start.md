# 0. С чего начать

## Результат

К концу первого занятия на Mac должны быть:

- актуальный macOS;
- вход в Apple ID и включённый Find My;
- настроенный способ резервного копирования (лучше Time Machine, если есть внешний диск);
- ChatGPT Desktop;
- Homebrew;
- базовый набор программ из `Brewfile`.

## Не начинай с очистки

На почти пустом Mac нет смысла агрессивно удалять caches или “оптимизировать” систему. Mole полезен прежде всего как способ **увидеть**, что занимает место.

Первый запуск:

```bash
mo analyze
```

Если когда-нибудь действительно нужно очистить место, сначала посмотри план:

```bash
mo clean --dry-run
```

И только после просмотра — решай, нужен ли реальный `mo clean`.

Mole сам рекомендует preview перед удалением: <https://github.com/tw93/Mole>

## Первое упражнение

```

University/
├── Notes/
├── Projects/

```
