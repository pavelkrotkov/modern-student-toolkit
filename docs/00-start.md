# 0. Начало: подготовь Mac и способ получить помощь

## Перед началом

Нужно только:

- Mac;
- internet connection;
- твой ChatGPT account;
- обычный web browser.

**Terminal, Homebrew и Git пока не нужны.**

## 1. Открой этот курс и сохрани ссылку

Открой:

<https://pavelkrotkov.github.io/modern-student-toolkit/>

Добавь страницу в bookmarks. Пока курс живёт для тебя **в browser**, а не в локальной папке.

## 2. Сделай ChatGPT аварийным помощником

Открой <https://chatgpt.com/> и войди в свой account.

Если любой шаг курса не совпадает с тем, что ты видишь на экране, можно написать:

```text
Я прохожу Modern Student Toolkit, урок 0.
Я не программист. На шаге <номер> я вижу вот это: <опиши или приложи screenshot>.
Объясни по-русски, что делать дальше. Не пропускай промежуточные шаги.
```

Это важно: если рядом нет человека, Chat должен быть способом **разобраться**, а не поводом наугад пробовать команды.

## 3. Обнови macOS

Открой:

**Apple menu → System Settings → General → Software Update**

Установи обычные доступные updates. Если система предлагает крупный upgrade и ты не уверен — сначала спроси Chat.

## 4. Проверь Apple ID и Find My

В **System Settings** убедись, что ты вошёл в Apple ID и **Find My Mac** включён.

Backup через Time Machine мы ещё обсудим в maintenance; отсутствие внешнего диска не блокирует курс.

## 5. Создай учебную структуру в Finder

Открой Finder.

Нажми **Shift+Command+H** — это открывает твою **home folder**.

Создай папку `University`, а внутри неё четыре папки:

```text
University/
├── Notes/
├── Projects/
├── Sources/
└── Scratch/
```

Пока делай это мышью через Finder. В следующем уроке ты увидишь те же папки через Terminal.

## Checkpoint

Перед уроком 1 должно быть верно:

- [ ] курс сохранён в browser;
- [ ] ChatGPT открывается и ты можешь задать вопрос;
- [ ] `University` находится в твоей home folder;
- [ ] внутри есть `Notes`, `Projects`, `Sources`, `Scratch`.

Если хотя бы один пункт не выполнен — сначала открой [«Если застрял»](help.md).
