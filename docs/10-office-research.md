# 10. Учёба: документы, источники и перевод

## Перед началом

ONLYOFFICE, Zotero и DeepL были установлены в уроке 2. Если какое-то приложение пропущено:

```bash
brew install --cask onlyoffice zotero deepl
```

## ONLYOFFICE

ONLYOFFICE — бесплатный редактор документов для `.docx`, `.xlsx`, `.pptx`.

<https://www.onlyoffice.com/>

Проверь также, даёт ли университет Microsoft 365 Education. Для учебных заданий по бизнесу и логистике полноценный Excel может понадобиться из-за макросов VBA, надстроек или требований преподавателя.

<https://www.microsoft.com/education/products/office-365-education>

## Zotero

Начни пользоваться Zotero с первого задания, в котором нужно работать с источниками.

Используй его для:

- книг и статей;
- файлов PDF;
- сведений об авторах и публикациях;
- стилей оформления ссылок;
- списков литературы.

Краткое руководство:
<https://www.zotero.org/support/quick_start_guide>

## Перевод

Для обучения обычно полезнее Chat:

```text
Объясни этот текст по-русски.
При первом упоминании важных английских терминов указывай их в скобках.
Отдельно выпиши 8 терминов, которые мне нужно узнавать на английском.
```

DeepL удобен для быстрого буквального перевода отдельных фраз или документов.

## Папки курса для реальной учёбы

Сохраняй исходные материалы отдельно от собственных заметок:

```text
~/University/Sources/   # файлы PDF, наборы данных, исходные материалы
~/University/Notes/     # твои заметки в формате Markdown
```

Не добавляй большие PDF-файлы и наборы данных в закрытый репозиторий заметок без необходимости.

## Практика

Возьми одну реальную статью по предмету:

1. сохрани PDF в `~/University/Sources`;
2. добавь источник в Zotero;
3. создай заметку в Obsidian с пятью собственными тезисами;
4. попроси ChatGPT найти возможные пробелы в понимании;
5. попроси ChatGPT проверить твои знания пятью вопросами.

## Проверка результата

Ты должен понимать, где хранятся **исходные материалы**, а где — твои **заметки**, и для чего нужны Zotero и Obsidian.
