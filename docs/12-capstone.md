# 9. Итоговая работа: выполни новую задачу

**Время:** 45–60 минут. **Результат:** проверенная записка, таблица и объяснение расчёта.

## Перед началом

Пройдены уроки 0–8 либо явно отмечены отложенные технические шаги. Есть исходники поездки и таблица. Если Python пока недоступен, выполни расчёт в таблице и отметь программную проверку как отложенную. Нужные файлы можно получить прямо здесь: [costs-extra.csv](practice/costs-extra.csv){download="costs-extra.csv"} и [budget.py](practice/budget.py){download="budget.py"}.

## Задание

У организатора новое условие: **едут 10 человек**. Оно заменяет число участников из первоначального источника. Цены прежние, предел бюджета остаётся **180 евро**, блокнотов по-прежнему нужно по одному на двоих. Группа хочет добавить по одному перекусу каждому.

Подготовь ответ: укладывается ли поездка с перекусами в бюджет и какой запас остаётся? Не делай предположений о настоящих ценах, расписании или наличии билетов: здесь используются только учебные условия.

## Что подготовить

В Finder создай папку `~/University/Projects/Trip-Final`.

1. **Данные:** скопируй туда `costs-extra.csv` под именем `costs-final.csv`. Измени количество участников в соответствующих строках и количество блокнотов. Сохрани заголовки, запятые и десятичные точки. Удобно редактировать небольшой CSV в VS Code или в TextEdit в режиме простого текста; исходники сохраняются отдельно.
2. **Таблицу:** импортируй новый CSV в редактор из урока 4, рассчитай стоимость строк, итог и остаток бюджета. Сохрани `final-budget.xlsx`. Сделай диаграмму с понятными подписями и единицами измерения.
3. **Проверку:** скопируй исходный `budget.py` в `Trip-Final`, открой эту папку в Terminal и запусти его на новом CSV. Сравни с таблицей. Убедись, что `CATEGORY` пустая: нужны все расходы.
4. **Записку:** сохрани `final-note.docx` и `final-note.pdf`. До 150 слов: новое условие, расчёт, ответ на вопрос, два невыясненных обстоятельства и ссылки на условия и цены. Явно укажи, что число участников изменено заданием этого урока.
5. **Историю:** если локальная часть Git доступна, создай репозиторий только в `Trip-Final` и сохрани `budget.py` и `costs-final.csv` коммитом. Публикация на GitHub для итоговой работы не требуется.

ИИ может объяснять ошибки и помогать с оформлением. До передачи ему задачи запиши своё предположение об итоге. После получения результата открой файлы и проверь числа сам.

## Проверка результата без ИИ

Закрой чат. Пользоваться источниками и шпаргалками можно.

| Проверка | Что показать |
|---|---|
| Работа с файлами | Найти исходный CSV и новый CSV, объяснить разницу |
| Источники | Показать, откуда взята цена, и где изменилось условие |
| Расчёт | Вручную проверить одну строку и остаток бюджета |
| Программа | Объяснить чтение CSV, умножение и итоговый вывод |
| Документ | Открыть PDF и проверить числа, текст и ссылки |
| Восстановление | Объяснить, где сохранена исходная версия данных |

Отметь каждый пункт как **«сам»**, **«со шпаргалкой»**, **«с ИИ»** или **«пока не получилось»**. Для основных проверок цель — первые два варианта. Невыполненный пункт показывает, какое упражнение стоит повторить.

    Проезд — 80; музей — 40; блокноты — 12,50; вода — 10; фрукты — 7,50; перекусы — 20 евро. **Всего 170 евро**, запас — **10 евро**. Программа покажет 6 покупок. Дата поездки и наличие билетов остаются неизвестными.

## Через неделю

Возьми один настоящий учебный материал: открытую статью, главу или разрешённый преподавателем набор данных. Сохрани источник, сделай собственную заметку и попроси ИИ проверить один вывод. Подтверди его по оригиналу. Если есть числовые данные, проверь хотя бы одно вычисление вручную.

Не обязательно автоматизировать каждую задачу: выбери таблицу, программу или обычную заметку по тому, какой результат нужен.
