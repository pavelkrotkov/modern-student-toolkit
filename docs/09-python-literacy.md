## 2а. Проследи три расхода {#trace}

Открой Visual Studio Code → **File → Open Folder** → `First-Python`. Если появится запрос доверия папке, проверь, что выбрана именно твоя учебная папка с материалами курса. Создай **File → New Text File**, вставь пример и сохрани как `trace-total.py` в этой папке:

```python
expenses = [8, 4, 3]
total = 0
for expense in expenses:
    total = total + expense
    print(total)
```

Это три расхода в целых евро. `expenses` — список, `total` — накопленная сумма. Цикл `for` по очереди берёт каждое значение. Отступ показывает действия внутри цикла.

До запуска на бумаге заполни три строки: **расход → сумма до → сумма после**. Затем в Terminal из `First-Python` выполни `uv run --python 3.13 trace-total.py`. При первом запуске дождись загрузки Python.

??? tip "Подсказка"
    Начни с нуля. После первой строки с расходом не обнуляй сумму: следующий расход добавляется к уже накопленному. [Ещё одна подсказка](hints.md#python).

??? success "Проверка после прогноза"
    `8 → 0 → 8`, `4 → 8 → 12`, `3 → 12 → 15`. Программа печатает 8, 12 и 15, потому что `print` находится внутри цикла. Если перенести `total = 0` внутрь цикла, сумма будет начинаться заново на каждом шаге — это другая программа.

Если изменение переменных пока непонятно, открой [Python Tutor](https://pythontutor.com/), выбери Python, вставь **только этот короткий фрагмент** и пошагово сравни значения со своей таблицей. Это необязательный англоязычный инструмент в браузере; загружать CSV, личные файлы или весь `budget.py` туда не нужно. Закончи, когда сможешь объяснить каждый шаг; регистрация для обычного визуализатора не требуется.

**Маленькая самостоятельная попытка:** замени последний расход 3 на 5. Предскажи все три строки вывода, затем запусти. В полном `budget.py` происходит такое же накопление, только очередная сумма равна количеству × цене, а строки приходят из CSV.

## 3. Сначала предскажи, затем запусти

Открой Visual Studio Code → **File → Open Folder** → `First-Python`. Если редактор спрашивает о доверии, разрешай выполнение только после проверки происхождения файлов; здесь они из этого курса. Выбери `budget.py` в панели файлов.

Расширение `.py` обозначает текст программы. **Интерпретатор** выполняет её команды. Программа читает CSV и печатает сумму; исходные данные не изменяет.

До запуска запиши ожидаемую сумму из урока 4. Затем в Terminal, находясь в `First-Python`, выполни:

```bash
uv run --python 3.13 budget.py costs.csv
```

Первый запуск может загрузить Python; дождись окончания. В конце должно появиться:

```text
Строк расходов: 5
Итого: 180.00 евро
```

Счётчик показывает число подходящих строк CSV, а не количество отдельных предметов. Сравни сумму с `budget.xlsx`.

## 4. Прочитай программу по частям

| Фрагмент | Что он делает |
|---|---|
| `import csv` | Подключает готовые средства чтения CSV из стандартной библиотеки |
| `Decimal` | Позволяет считать десятичные цены без ошибок двоичного округления |
| `CATEGORY = ""` | Переменная задаёт, какие категории учитывать; пустая строка выбирает все |
| `def calculate(...)` | Определяет функцию — именованную последовательность действий |
| `open(...)` и `csv.DictReader` | Открывают файл и читают строки по названиям столбцов |
| `for row in rows` | Повторяет действия для каждой покупки |
| `if ...` | Проверяет условие: подходят ли данные или категория |
| `total += quantity * price` | Добавляет стоимость очередной покупки |
| `try` / `except` | Позволяет сообщить об ошибке чтения или данных |
| `print(...)` | Показывает итог в Terminal |

Отступы в Python определяют, какие строки относятся к циклу, условию или функции. Не меняй их случайно. Строки с `#` — комментарии для читателя.

Можно попросить Chat или Codex объяснить **один** непонятный фрагмент, приложив код:

```text
Объясни функцию calculate на примере строки с блокнотами.
Сначала спроси, какой результат я ожидаю. Не изменяй код.
```

## 5. Измени один параметр

Сохрани через **File → Save As** копию программы с именем `budget-food.py`. В ней замени только `CATEGORY = ""` на `CATEGORY = "food"`, сохрани через Command+S.

Предскажи сумму воды и фруктов, затем:

```bash
uv run --python 3.13 budget-food.py costs.csv
```

Ожидается **2 строки расходов, 21.00 евро**. Первоначальный `budget.py` по-прежнему должен считать все расходы.

## 6. Разберись с одной ошибкой

```bash
uv run --python 3.13 budget.py missing.csv
```

Ошибка ожидаема: файла `missing.csv` нет. В сообщении будет `Не удалось посчитать` и описание проблемы с файлом. Посмотри `pwd`, `ls` и исправь последний аргумент команды на существующее имя. Не переустанавливай Python из-за ошибки имени файла.
