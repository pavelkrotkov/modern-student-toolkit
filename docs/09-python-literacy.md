# 9. Python без курса программирования

## Перед началом

Ты уже изучил Git, установил навык `$teach-me`, и он работает. Python пока мог вообще не быть установлен — это нормально.

Цель — не «выучить Python», а научиться понимать небольшие программы, запускать их и обсуждать изменения с Codex.

## 1. Установи инструменты только сейчас

```bash
brew install uv ripgrep
brew install --cask visual-studio-code
```

Проверка:

```bash
uv --version
rg --version
```

`uv` может самостоятельно установить подходящую версию Python и подготовить окружение проекта.

Документация:
<https://docs.astral.sh/uv/>

## Что нужно знать

- `.py` — расширение текстового файла с кодом на Python;
- **интерпретатор (interpreter)** выполняет код Python;
- **переменная (variable)** хранит значение;
- **функция (function)** — именованный участок программы, который выполняет определённую задачу;
- **библиотека или пакет (library / package)** — готовый код для повторного использования;
- **виртуальное окружение (virtual environment)** позволяет разделять зависимости разных проектов.

## 2. Создай первый проект

```bash
cd ~/University/Projects
uv init first-python-project
cd first-python-project
pwd
```

Теперь открой именно эту папку в Codex.

## 3. Попроси `$teach-me`

```text
$teach-me Я не программист.
Покажи мне, какие файлы создал `uv init`, и объясни, для чего они нужны.
Затем помоги запустить простейшую программу на Python.
Не добавляй лишних библиотек.
```

Если позже будешь работать с настоящим файлом CSV, попроси Codex сначала объяснить содержимое данных и предложить небольшой анализ.

Например, чтобы добавить библиотеку:

```bash
uv add pandas
```

Запуск программы:

```bash
uv run python main.py
```

## Что считать успехом

Ты можешь открыть 20–40 строк простого Python и примерно объяснить:

- откуда поступают данные;
- что вызывается;
- какой результат выдаёт программа;
- где изменить имя файла или параметр;
- как запустить его снова.

Этого достаточно для первой версии курса.
