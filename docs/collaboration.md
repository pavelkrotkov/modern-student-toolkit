# 4б. Совместная работа и сдача результата

**Время:** 60–90 минут, включая итог базового маршрута; ожидание ответа партнёра отдельно. **Результат:** получатель открывает нужную версию документа с подходящими правами.

## Перед началом

Пройдены уроки 0–4а. Есть `trip-note.docx`, проверенный бюджет и PDF. Нужны разрешённая учебная учётная запись и партнёр: однокурсник, друг или родственник, согласившийся проверить учебный файл. Паролями не обменивайтесь.

Основной редактор — **ONLYOFFICE**. Для этого упражнения нужен доступ к **ONLYOFFICE DocSpace**: общему хранилищу с редактором в браузере. Один локальный файл в Desktop Editors не предоставляет общую историю и права доступа.

Если у вас уже есть DocSpace, используй его. Иначе открой [варианты подключения и создания DocSpace](https://helpcenter.onlyoffice.com/desktop/connection/desktop-connect-saas.aspx): в Desktop Editors есть раздел **Clouds** и кнопка `+`. Проверь условия выбранного варианта; платная подписка для прохождения курса не является требованием. После создания пространства можно работать в браузере. Партнёру тоже потребуется учётная запись и доступ в это пространство; при необходимости попроси его администратора пригласить участника. Не меняй настройки всей организации ради упражнения.

Если DocSpace недоступен, используй вариант с копиями ниже и отметь, какие облачные действия остались непроверенными.

## 1. Подготовь одну рабочую версию

В DocSpace открой **My documents**, загрузи **копию** `trip-note.docx` и открой её. Добавь строку «Учебный пример; версия для проверки». Локальный исходник остаётся в `Projects/Trip`. Закрой вкладку документа и снова открой его из списка: проверь, сохранилась ли строка.

## 2. Выдай нужные права

1. В открытом документе нажми **Share**; в панели доступа выбери **Invite contacts**.
2. Найди учётную запись партнёра среди контактов пространства, выбери право **Comment** и подтверди выбор кнопкой **Select**.
3. Проверь указанного получателя и его права. **Read only** — чтение; **Comment** — замечания; **Editing** — изменение текста. Для этой задачи достаточно комментариев.
4. Попроси партнёра найти файл в **Shared with me** и подтвердить название и последнюю строку из своей учётной записи. Затем проверьте, может ли он оставить замечание.

Быстрая команда **Copy shared link** может создать ссылку для любого, кто её получит. Для этого упражнения выбирай конкретного человека. В DocSpace личные права имеют приоритет над групповыми, а групповые — над правами по ссылке. Сверь персональное разрешение и фактические действия получателя; [правила приоритета](https://helpcenter.onlyoffice.com/docspace/administration/docspace-managing-documents.aspx) помогают разобрать расхождение.

[Права и способы передачи в DocSpace](https://helpcenter.onlyoffice.com/docspace/administration/docspace-sharing-documents.aspx). **Проверено по документации: 2026-10-07.**

## 3. Обработай замечание и найди прежнюю версию

Попроси партнёра выделить число или вывод → **Collaboration → Comment** → написать «Покажи источник и расчёт». Ответь через **Add Reply**, при необходимости исправь текст. Закрой обсуждение кнопкой **Resolve** только после проверки. Если вы используете право **Review**, вместо комментария можно предложить исправление; автор проверяет его и принимает либо отклоняет.

Оба участника должны закрыть редактор. В DocSpace новая версия обычно сохраняется после завершения сеанса всеми участниками; это может занять около десяти секунд. У файла открой контекстное меню → **Properties → Show version history**. Открой предыдущее состояние, сравни исправленную строку, затем вернись к текущему. Для упражнения достаточно просмотра: восстанавливать прежнюю версию поверх работы партнёра не нужно.

[Комментарии ONLYOFFICE](https://helpcenter.onlyoffice.com/docs/userguides/document_editor/Commenting.aspx) · [Версии DocSpace](https://helpcenter.onlyoffice.com/docspace/administration/docspace-document-versions.aspx).

Если партнёр пока не ответил, можно потренироваться на собственном комментарии. Отметь это как репетицию; проверка доступа и чужого замечания пока не завершена.

??? info "Если доступен только ONLYOFFICE Desktop Editors"
    Сохрани исходную копию как `trip-review-v1.docx` и передай её согласившемуся партнёру через разрешённый канал. Партнёр открывает её в ONLYOFFICE, добавляет комментарий и возвращает `trip-review-commented.docx`. Обработай замечание, сохрани `trip-review-v2.docx` и сравни с `v1`.

    Затем выполни проверку отправленного PDF ниже. Это позволяет закончить практику замечаний, версий и сдачи. Права общего документа и автоматическую историю DocSpace отметь как отложенные: обмен файлами не проверяет эти функции. Копия у получателя остаётся у него даже после удаления твоего файла.

## 4. Проверь именно отправленную копию

После исправления выгрузи PDF через **File → Download as → PDF** в DocSpace или **File → Save as → PDF** в Desktop Editors. Назови его `trip-final-YYYY-MM-DD.pdf`, заменив дату на сегодняшнюю. Открой его в Preview: проверь итог, последнюю правку, ссылки и переносы. PDF после изменения онлайн-документа нужно выгрузить заново.

Передай окончательный PDF через согласованный канал или учебную систему. Если это упражнение, не сдавай его как настоящий ответ преподавателю. Открой предварительный просмотр вложения или скачай файл из отправленного сообщения/учебной системы: это должна быть та же последняя версия. Попроси получателя подтвердить доступ и увидеть исправленную строку. Сохрани статус/квитанцию сдачи, если система их выдаёт.

Запиши в `Course-progress.txt`: что передано, какая версия, какие права, чем подтверждён доступ. Личные адреса и переписку в публичную обратную связь не копируй.

## Итог базового маршрута {#essential-finish}

Закрой ИИ. За 20–30 минут подготовь **одну страницу по своему настоящему вопросу из урока 2**: ответ своими словами, два утверждения с точными ссылками, одно ограничение и два вопроса для повторения. Сверь с таблицей доказательств, сохрани PDF, найди его в Finder и покажи партнёру или наставнику. Источниками и шпаргалками пользоваться можно.

Покажи также свою таблицу из урока 4а и объясни одну исправленную ошибку. По журналу восстановления назови место независимой копии и восстановленный тестовый файл. Для каждой проверки отметь: **сам / со шпаргалкой / с ИИ / пока не получилось**.

- [ ] Я могу показать подтверждение утверждения и границу своего вывода.
- [ ] Я обнаружил ошибку в таблице и проверил исправленный итог.
- [ ] Получатель открыл нужную версию с подходящими правами; замечание обработано.
- [ ] Я проверил отправленный PDF и восстановил тестовый файл из независимой копии.
- [ ] Итоговую страницу подготовил сам или со шпаргалкой.

**Это самостоятельный, полноценный результат курса.** Если эти пункты выполнены, базовый маршрут завершён. При варианте с локальными копиями укажи ограничение: права и автоматическая история общего документа ещё не проверены; остальные результаты засчитываются. Terminal, Git и Python можно выбрать позже, когда появится задача. Невыполненный пункт требует конкретной повторной попытки, а не прохождения всех технических уроков.

**Слова занятия:** права доступа — разрешённые действия получателя; версия — состояние документа в определённый момент; сдача — передача проверенного результата с подтверждением получения.

**Попробуй сам:** объясни, чем отличается право комментировать от права редактировать, и проверь это с партнёром на учебном документе.

**Завтра:** найди итоговый PDF по имени, проверь одно число и ответь на один вопрос из заметки без чата. **Примерно через неделю:** выполни [задачу в другом контексте](transfer-check.md). Это практический график повторения, а не обещание научно оптимального интервала.
