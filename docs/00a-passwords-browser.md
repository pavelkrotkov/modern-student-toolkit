# 0а. Браузер, пароли и секретные ключи: Brave и Bitwarden

**Время:** 35–45 минут на Mac; настройка телефона — ещё 10–15 минут по желанию. **Результат:** ты умеешь входить на сайты через Bitwarden, хранить секретные ключи отдельно от ИИ и справляться с сайтом, который не работает в Brave.

## Перед началом

Нужны Mac, доступ к своей почте и интернет. Если пользуешься семейным или учебным устройством, сначала уточни разрешение на установку программ. Terminal, Git и платные подписки не нужны. У тебя уже должна быть понятна [проверка восстановления почты из урока 0](00-start.md).

## 1. Выбери браузер: Brave для повседневной работы, Safari на случай проблем

**Рекомендую Brave**: он изначально блокирует значительную часть рекламы и средств отслеживания между сайтами. Это уменьшает отвлекающие элементы, но не делает тебя анонимным и не гарантирует защиту от всех угроз.

1. Открой [официальную страницу Brave](https://brave.com/download/) в нынешнем браузере. Скачай вариант для Mac.
2. Открой загруженный файл, перетащи **Brave** в **Applications / «Программы»**, запусти через Finder или Spotlight (**Command+Space**).
3. Открой этот курс в Brave, добавь его в закладки (**Command+D**). **Safari оставь установленным**: он уже есть на Mac и пригодится как второй браузер.

Если Brave понравится, можешь сделать его браузером по умолчанию: ** → System Settings → Desktop & Dock → Default web browser → Brave**. Это необязательно.

Защита Brave называется **Shields** (значок льва/щита возле адреса страницы). Иногда из-за блокировки не загружаются вход, оплата, видео или часть учебного сайта.

**Если надёжный сайт не работает:**

1. Перезагрузи страницу. Проверь адрес сайта: отключение защиты не исправляет поддельный адрес.
2. Нажми значок Shields возле адреса и **выключи Shields только для этого сайта** (Shields Down). Обнови страницу и попробуй снова. Не выключай защиту сразу для всех сайтов.
3. Если не помогло, открой тот же адрес в **Safari**. После проверки при желании снова включи Shields на исходном сайте.

[Brave: установка на Mac](https://support.brave.com/hc/en-us/articles/360025390311-How-do-I-download-and-install-Brave) · [Brave: исключения для отдельных сайтов](https://support.brave.com/hc/en-us/articles/360023646212-How-do-I-configure-global-and-site-specific-Shields-settings)

## 2. Создай Bitwarden и сохрани способ восстановления

**Bitwarden** — отдельное зашифрованное хранилище паролей, кодов восстановления и других секретов. Оно синхронизируется между твоими устройствами. Начать можно с бесплатной учётной записи.

1. Перейди на [официальный сайт Bitwarden](https://bitwarden.com/) и выбери создание бесплатной учётной записи. Используй **свою доступную почту**.
2. Придумай **основной пароль** (master password): длинную уникальную парольную фразу, которую не используешь на других сайтах. Пароли остальных сайтов Bitwarden сможет создавать сам.
3. **Сохрани основной пароль вне Bitwarden**, например на бумаге в надёжном месте. Не помещай единственную копию внутрь этого же хранилища. Если забыть основной пароль, Bitwarden обычно не сможет его восстановить.
4. В веб-хранилище открой **Settings → Security → Two-step login** и включи дополнительную проверку входа доступным тебе способом. **Код восстановления самого Bitwarden сохрани отдельно от Bitwarden и потеряемого телефона**, например рядом с бумажной записью основного пароля в защищённом месте. Этот код помогает при потере второго фактора, **но не заменяет основной пароль**.

До переноса всех паролей проверь, что можешь входить в Bitwarden и получать сообщения на свою почту. Не удаляй существующие пароли из Apple Passwords или браузера, пока не проверил вход с Bitwarden.

[Bitwarden: основной пароль](https://bitwarden.com/help/master-password/) · [дополнительная проверка входа](https://bitwarden.com/help/setup-two-step-login/) · [код восстановления](https://bitwarden.com/help/two-step-recovery-code/)

## 3. Установи Bitwarden в браузере на Mac

Выбери один или оба способа. **Расширение** — небольшая часть Bitwarden внутри браузера; оно предлагает сохранённые данные на подходящем сайте.

=== "Brave"

    1. В Brave открой [страницу загрузок Bitwarden](https://bitwarden.com/download/), найди расширение **Chrome**: Brave использует тот же магазин расширений.
    2. В **Chrome Web Store** выбери официальный **Bitwarden Password Manager** и нажми **Add to Brave / «Добавить в Brave»**. Проверь имя разработчика, не устанавливай похожее расширение из рекламы.
    3. Нажми значок расширений возле адресной строки (пазл), закрепи **Bitwarden** значком булавки.
    4. Открой значок Bitwarden, войди в свою учётную запись и разблокируй хранилище.

=== "Safari на Mac"

    1. Из [загрузок Bitwarden](https://bitwarden.com/download/) открой **Mac App Store** и установи **Bitwarden Password Manager** для Mac.
    2. **Запусти приложение Bitwarden хотя бы один раз** и войди в свою учётную запись.
    3. В Safari открой **Safari → Settings → Extensions**, отметь **Bitwarden** и подтверди включение (**Turn On**). Разрешения расширения проверь в системном диалоге.
    4. Открой значок Bitwarden в Safari и проверь вход. **Расширение Safari поставляется с приложением из Mac App Store**; версия Bitwarden, установленная с сайта через файл `.dmg`, не добавляет это расширение в современный Safari.

Приложение Bitwarden для Mac можно установить и при работе в Brave, но для обычного заполнения форм в Brave достаточно расширения браузера.

Если браузер и Bitwarden оба предлагают сохранять пароли, выбери **Bitwarden** как основной менеджер. В его расширении открой **Settings → Autofill → Make Bitwarden your default password manager**, если пункт доступен. Для Brave можно также открыть `brave://password-manager/settings` и выключить сохранение паролей встроенным менеджером. Сначала убедись, что старые записи перенесены и работают; не удаляй их вслепую.

[Bitwarden: расширения браузеров](https://bitwarden.com/help/getting-started-browserext/) · [расширение Safari](https://bitwarden.com/help/install-safari-app-extension/) · [два менеджера паролей](https://bitwarden.com/help/disable-browser-autofill/)

## 4. Сохрани один вход и проверь заполнение

1. Выбери **некритичную учётную запись**, пароль от которой ты знаешь (не основную почту). В расширении Bitwarden открой **Vault → New → Login**.
2. Запиши название сервиса, имя пользователя, **существующий пароль** и правильный адрес сайта (**Website / URI**). Нажми **Save**. Адрес нужен, чтобы Bitwarden предлагал вход именно на этом сайте.
3. Открой страницу входа. Нажми значок Bitwarden и выбери нужную запись для **Autofill**; при поддержке браузером работает также **Command+Shift+L**. Проверь, что вход удался.
4. При следующей **смене пароля на самом сайте** используй генератор Bitwarden для нового, длинного и уникального пароля. Сохрани его в записи и проверь, что сайт действительно принял изменение. **Запись в Bitwarden сама по себе не меняет пароль на сайте.**

Если заполнение не срабатывает, сначала проверь адрес сайта в записи и попробуй выбрать её вручную. Не включай автоматическое заполнение сразу при загрузке страницы: по умолчанию оно выключено не случайно.

[Bitwarden: заполнение форм](https://bitwarden.com/help/auto-fill-browser/)

## 5. Секретные ключи храни в Bitwarden, но не показывай ИИ

**Пароль, токен, ключ API (API key), резервный код входа или закрытый SSH-ключ** могут давать доступ к учётной записи или сервису. ИИ не нужно видеть их настоящие значения, чтобы объяснить настройку программы.

| Что у тебя есть | Куда поместить в Bitwarden |
|---|---|
| Логин и пароль сайта | **Login** с адресом сайта для заполнения |
| Ключ API, токен или код восстановления другого сайта | **Secure note** (защищённая заметка) или **Hidden** (скрытое дополнительное поле) в записи сервиса |
| Ключ доступа для входа без пароля (passkey) | Сохрани в **Login**, когда сайт и Bitwarden предложат это сделать |
| Пара SSH-ключей для Git или сервера | Необязательный тип **SSH key**: закрытая часть секретна, публичную можно передавать сервису |

**Практика без настоящих ключей:** открой **Vault → New → Secure note**, назови её «Тренировка: ключ API», впиши `ЭТО_НЕ_КЛЮЧ_123` и сохрани. Открой запись повторно. Для настоящего короткого токена можно вместо заметки добавить в запись сервиса **Custom field → Hidden**, чтобы значение не показывалось обычным текстом. Скрытие на экране не отменяет необходимости защищать доступ к хранилищу.

Когда сервису нужен реальный ключ, копируй его **из Bitwarden непосредственно в поле доверенного сервиса**, а не в сообщение ИИ. В учебном запросе используй условное обозначение, например `YOUR_API_KEY`. Не помещай ключи в скриншоты, файлы курса, общие документы и GitHub — даже в закрытый репозиторий. Не открывай настоящие секреты перед ИИ-агентом, которому разрешено видеть экран или управлять приложениями. Bitwarden не передаёт секреты программам автоматически: для программы или автоматизации используй предназначенные для этого настройки секретов, без вставки ключа в текст запроса агенту. Если ключ уже попал в чат или опубликованный файл, **отзови его и создай новый в выпустившем сервисе**; просто удалить сообщение недостаточно.

Позже, если действительно понадобятся SSH-ключи, изучи [их создание и хранение](https://bitwarden.com/help/about-ssh/) и [SSH Agent для Mac](https://bitwarden.com/help/ssh-agent/). Для начального урока Git по HTTPS это не требуется. Bitwarden **Secrets Manager** для автоматизированных проектов — отдельный продукт, устанавливать его ради этого урока не нужно.

[Bitwarden: типы записей](https://bitwarden.com/help/managing-items/) · [скрытые поля](https://bitwarden.com/help/custom-fields/)

## 6. Подключи телефон (по желанию)

**iPhone или iPad:** установи **Bitwarden Password Manager** из App Store по ссылке с [официальной страницы загрузок](https://bitwarden.com/download/), войди в ту же учётную запись. Открой **Settings → General → AutoFill & Passwords**, включи **AutoFill Passwords and Passkeys** и выбери **Bitwarden** в списке источников. При желании отключи конкурирующее заполнение паролей, чтобы не видеть два предложения. Это работает в приложениях, Safari и Brave на iPhone **через системное заполнение**, а не через расширение Chrome для настольного браузера.

**Android:** установи официальное приложение Bitwarden через Google Play. В Bitwarden открой **Settings → Autofill**, включи службу заполнения и выбери Bitwarden в открывшихся настройках Android. Названия пунктов могут отличаться у производителей телефонов. Для Brave и других мобильных браузеров используй приложение и системное заполнение, а не настольное расширение.

Разблокировку по Face ID, Touch ID или отпечатку пальца можно включить после первого входа, если устройство это поддерживает. Она не заменяет сохранённый способ восстановления учётной записи.

[Bitwarden: iPhone и iPad](https://bitwarden.com/help/auto-fill-ios/) · [Bitwarden: Android](https://bitwarden.com/help/auto-fill-android/)

## Проверка результата

- [ ] Открываю курс в Brave и знаю, где значок Shields и как сделать исключение **только для одного сайта**.
- [ ] Safari остаётся доступным как запасной браузер.
- [ ] Могу открыть Bitwarden через расширение на Mac и заполнить вход на знакомом сайте.
- [ ] Знаю, где **вне Bitwarden** хранится способ восстановления доступа к самому Bitwarden.
- [ ] Создал запись с **вымышленным** ключом, но не отправлял настоящее значение ИИ.
- [ ] Если настроил телефон: вижу учебную запись в приложении и могу найти системное автозаполнение.

**Попробуй сам:** объясни, почему закрытый SSH-ключ и ключ API нельзя отправлять ИИ, а публичный SSH-ключ обычно можно. На примере вымышленного ключа покажи, где в Bitwarden он хранится, не раскрывая никаких настоящих данных.

**Завтра:** открой Bitwarden и без подсказок найди пробную заметку; повтори, где выключить Shields для отдельного сайта.

**Слова занятия:** менеджер паролей — программа для хранения и заполнения учётных данных; основной пароль — секрет, открывающий хранилище; токен — секрет для доступа к сервису; закрытый ключ — секретная часть пары ключей; автозаполнение — подстановка сохранённых данных в поле сайта.
