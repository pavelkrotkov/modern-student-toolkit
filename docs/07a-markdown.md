# 3а. Markdown: текст для заметок и работы с ИИ

**Время:** 15–20 минут. **Результат:** ты умеешь читать и изменять файл `.md`, понимать основные обозначения и проверять его в другом приложении.

## Перед началом

Пройден урок 3: в `~/University/Notes/Courses/Toolkit` уже есть `MIT-intro.md`. Достаточно Obsidian или редактора простого текста, например TextEdit. Git и учётная запись Google не нужны.

## 1. Один файл — текст и оформление

**Markdown** — способ обозначать структуру обычного текстового файла. Вместо кнопки «Заголовок» ты можешь написать `# Заголовок`, вместо кнопки «Жирный» — `**важное**`. Файл обычно имеет расширение `.md`. Его можно открыть и прочитать даже без специальной программы.

Посмотри на исходный текст:

```markdown
# План исследования

**Вопрос:** Как проверить источник?

- Найти автора.
- Сверить утверждение с первоисточником.

[Материал MIT](https://missing.csail.mit.edu/2026/course-shell/)
```

Obsidian и GitHub могут показать тот же текст как оформленный документ: заголовок, выделенный вопрос, список и ссылку. **Исходный текст** содержит знаки `#`, `**`, `-`; **режим чтения** показывает оформление. Содержимое файла остаётся текстом, а не превращается в изображение или специальный формат редактора.

Основные обозначения собраны в [шпаргалке Markdown](cheatsheets/markdown.md). Её не нужно учить наизусть.

## 2. Почему Markdown удобен для работы с ИИ-агентами

Markdown часто служит **общим форматом для человека и ИИ**: в нём удобно писать задания, планы, пояснения и отчёты, сохранять результаты в файлах и видеть построчные изменения. Заголовки и списки помогают читать структуру, а обычный текст легко передавать между приложениями.

Можно попросить агента: «Подготовь план исследования в Markdown с заголовками, списком задач и ссылками на источники. Сохрани как `plan.md`». Затем открой файл и проверь содержание: **Markdown упрощает проверку, но не подтверждает правильность фактов**.

Это не обязательный «язык всех агентов» и не язык программирования. Для таблиц данных, точного обмена с программами или готовой работы преподавателю могут лучше подойти CSV, JSON, XLSX, DOCX или PDF. Варианты Markdown тоже различаются: например, ссылки вида `[[MIT-intro]]` работают в Obsidian, но не в любом редакторе.

## 3. Допиши свою заметку

1. Открой `MIT-intro` в Obsidian из урока 3. Добавь в конец **своей** заметки следующие строки:

   ```markdown
   ## Мои следующие шаги
   - [ ] Сверить вывод с исходным материалом.
   - [ ] Придумать свой пример.

   **Файл заметки:** `MIT-intro.md`

   [Открыть источник MIT](https://missing.csail.mit.edu/2026/course-shell/)
   ```

2. Переключись в режим чтения Obsidian и сравни заголовок, список, выделение и ссылку с исходным текстом. Квадратные скобки в списке задач поддерживаются Obsidian; это расширение базового Markdown.
3. В Finder найди `~/University/Notes/Courses/Toolkit/MIT-intro.md`. Это **тот же файл**, а не отдельная копия в Obsidian. Если Obsidian нет, добавь строки через TextEdit в режиме простого текста и проверь, что имя оканчивается именно на `.md`, а не `.md.txt`.

## 4. А Google Docs?

**Проверено по документации Google: 2026-10-09.** С 2024 года Google Docs умеет импортировать и экспортировать Markdown, а также вставлять текст **из Markdown** и копировать выделение **как Markdown**. В обычном документе для двух последних действий открой **Tools → Preferences → Enable Markdown**; файл можно скачать через **File → Download → Markdown (.md)**. [Инструкция Google](https://support.google.com/docs/answer/12014036?hl=en).

**Новое с 5 октября 2026 года:** Google объявил возможность **открывать и редактировать сам файл `.md` в Docs без преобразования в Google-документ**, совместно работать с ним и просматривать оформление в Drive. Эта функция вводится постепенно в течение **до 15 дней с 5 октября**, поэтому на твоём аккаунте её может ещё не быть. [Объявление Google](https://workspaceupdates.googleblog.com/2026/10/preview-edit-and-collaborate-on-Markdown-files-natively-across-Drive-and-Docs.html) · [Инструкция для `.md`](https://support.google.com/docs/answer/18289341?hl=en).

**Необязательная проверка:** создай в Finder копию `MIT-intro.md`, загрузи её в Google Drive и дважды щёлкни по файлу. Если новый режим уже доступен, в Docs рядом с названием будет пометка `.md`, а тип файла сохранится. В Drive можно открыть **Preview** и переключаться между текстом Markdown и оформленным видом. Не загружай личные заметки только ради опыта; достаточно учебной копии.

Не путай новый режим с прежним импортом, который **преобразовывал `.md` в документ Google**. Кроме того, Markdown не поддерживает все возможности Docs: при редактировании `.md` могут пропадать цвета, выделения фоном и выравнивание, а «умные чипы» превращаться в ссылки или текст. Для сложного оформления используй документ Google или DOCX; исходную копию `.md` сохрани. [Ограничения в справке Google](https://support.google.com/docs/answer/18289341?hl=en).
