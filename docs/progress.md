# Мой прогресс и повторение

Скопируй этот образец в `~/University/Notes/Course-progress.txt` или заметку Obsidian. Сайт ничего не сохраняет за тебя. Для заполнения достаточно одного выполненного упражнения; настройка сервиса учёта не нужна.

```text
Дата и упражнение:
Результат: имя файла или другая проверяемая работа
Время активной работы / ожидание установки или ответа:
Помощь: сам / со шпаргалкой / с ИИ / пока не получилось
Что я проверил и какое расхождение заметил:
Следующая попытка: конкретное действие и примерная дата
Результат повторения:
```

Запись «урок прочитан» не равна выполненному упражнению. Если сначала решил с ИИ, а затем без него, сохрани обе оценки. Снимки чужих аккаунтов, пароли и коды восстановления сюда не добавляй.

## Короткое смешанное повторение

После базового маршрута отведи 10–15 минут примерно через день:

1. Найди свой итоговый PDF через Finder, не открывая редактор.
2. По одной ссылке найди точное подтверждение предложения.
3. В копии бюджета измени количество и проверь, попала ли последняя строка в итог.
4. Ответь на два вопроса из заметки до перечитывания.

После технического маршрута добавь ещё одно действие: покажи разницу учебного файла в Git **или** предскажи результат программы для изменённых данных. Не нужно повторять все команды каждый день.

Через 5–10 дней после завершения выбранного маршрута выполни [новую задачу](transfer-check.md). Выбери удобный день; этот диапазон — организационный ориентир. Готово, когда сохранены работа, проверка и честная отметка помощи, а не только дата повторения.
