# 4. Codex: папки, браузер и управление компьютером

## Перед началом

- приложение ChatGPT для Mac установлено;
- папка `~/University/Projects/Codex-Practice` создана в уроке 1;
- ты понимаешь `pwd`, `ls`, `cd`.

`$teach-me` пока не нужен.

## Главная идея

**Открыть папку в Codex** и **дать агенту управлять компьютером (Computer Use)** — разные действия.

## 1. Открой папку для упражнений в Codex

1. Открой приложение ChatGPT для Mac.
2. Выбери **Codex**.
3. Начни новый чат.
4. Выбери действие **Open folder / Open local folder** и укажи:

```text
University → Projects → Codex-Practice
```

Согласно справке OpenAI, Codex на компьютере может работать с локальными папками, репозиториями и Terminal:
<https://help.openai.com/en/articles/20001275-chatgpt-work-and-codex>

Если название кнопки изменилось, не угадывай: спроси обычный Chat и приложи снимок экрана.

## 2. Сначала изучи содержимое, ничего не меняя

Отправь Codex:

```text
Я учусь работать с папками.
Пока ничего не меняй.
Покажи, какие файлы видишь в открытой папке,
и объясни, что означает рабочая директория.
```

Сравни список с Finder.

## 3. Одно контролируемое изменение

```text
Предложи создать внутри этой папки подпапку `archive`.
Сначала объясни, что именно изменится.
Не перемещай другие файлы без моего подтверждения.
```

После создания проверь изменение в Finder.

## 4. Почему важно ограничивать область доступа

Для упражнения Codex нужна только `Codex-Practice`.

Не открывай `~` или весь диск “на всякий случай”. Доступ только к нужной папке:

- проще понять;
- проще проверить;
- уменьшает случайные изменения;
- лучше объясняет агенту, с каким проектом он работает.

## 5. Прямая работа с файлами обычно лучше щелчков мышью

Если задачу можно выполнить непосредственно с файлом или командой, результат обычно легче проверить, чем при работе через графический интерфейс.

Позже, после установки `ripgrep`, поиск по Markdown может выглядеть так:

```bash
rg "economics" ~/University/Notes
```

Пока эту команду запускать не нужно.

## 6. Встроенный браузер

Браузер нужен, когда задача связана с сайтом или веб-приложением.

В Work или Codex открой встроенный браузер через панель инструментов или сочетанием клавиш:

```text
Command+Shift+B
```

Справка OpenAI:
<https://help.openai.com/en/articles/20001277-using-the-built-in-browser-in-the-chatgpt-desktop-app>

## 7. Управление компьютером (Computer Use)

Управление компьютером (Computer Use) нужно, когда агент должен **видеть графическое приложение и работать с ним**: нажимать кнопки, вводить текст, открывать настройки.

Пример:

```text
Помоги мне найти в настройках Obsidian раздел Community plugins.
Ничего не устанавливай без моего подтверждения.
```

Предпочтительный порядок:

1. прямая работа с файлами или программным интерфейсом (API);
2. Terminal и команды;
3. браузер;
4. Computer Use.

## 8. Запись и повторение действий (Record & Replay) — позже

На поддерживаемых Mac и тарифных планах Codex может записать продемонстрированную последовательность действий в графическом интерфейсе и превратить её в повторно используемый навык. Пока достаточно знать, что такая возможность существует.

Справка:

## Проверка результата

Ты должен уметь:

- открыть только `Codex-Practice`;
- попросить Codex сначала изучить файлы, а не изменять их;
- объяснить разницу между доступом к папке и управлением компьютером.
