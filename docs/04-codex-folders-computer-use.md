# 4. Codex: папки, browser use и Computer Use

Самая важная идея: **доступ к папке и Computer Use — разные вещи**.

## 1. Работа с локальной папкой

Когда Codex открыт на конкретной папке, он может читать/изменять файлы и использовать Terminal в пределах доступного контекста.

Первое упражнение:

1. Открой `~/University/Codex-Practice` в Codex.
2. Напиши:

```text
Сначала ничего не меняй. Покажи, какие файлы видишь в этой папке,
и объясни, что означает working directory.
```

3. Потом:

```text
Создай папку archive и предложи, какой из тестовых файлов туда перенести.
Сначала объясни план. После моего подтверждения сделай изменение.
```

Главная привычка: **открывай минимальную нужную папку**, а не домашнюю директорию целиком.

OpenAI: Work desktop может получать доступ к выбранным локальным папкам; Codex предназначен для технической работы с проектами и окружением:
<https://help.openai.com/en/articles/20001275-chatgpt-work-and-codex>

## 2. Files/Terminal обычно лучше GUI

Если задачу можно выполнить непосредственно с файлом или командой, это обычно проще проверить и повторить.

Например, чтобы найти слово в Markdown-файлах:

```bash
rg "economics" ~/University/Notes
```

Codex может выполнить такую команду и показать результат. Это лучше, чем открывать каждый файл визуально и нажимать Search.

## 3. Browser use

Используй browser, когда работа действительно живёт на сайте: исследование, веб-приложение, загрузка материала, проверка страницы.

Пример:

> Открой страницу сегодняшней лекции Missing Semester. Объясни выделенный раздел по-русски, но сохрани английские технические термины.

## 4. Computer Use

Computer Use нужен, когда задача требует **видеть и управлять графическим приложением**: кликать, печатать, открывать настройки.

Пример:

> Помоги мне найти в Obsidian настройки Community plugins. Ничего не устанавливай без подтверждения.

Не используй Computer Use только потому, что он эффектный. Предпочтение:

1. файл/API;
2. Terminal/command;
3. browser;
4. Computer Use.

Это обычно быстрее, прозрачнее и легче проверить.

## 5. Record & Replay

На eligible macOS accounts Codex поддерживает **Record & Replay**: можно один раз показать стабильный GUI workflow и превратить его в reusable skill. Это продвинутый материал — вернись к нему после skills.

Актуальная справка:
<https://help.openai.com/en/articles/11369540-using-codex-with-your-chatgpt-plan>

## Практика `$teach-me`

```text
$teach-me Я впервые работаю с папкой через Codex.
Помоги мне понять, где находится рабочая директория,
посмотреть файлы и безопасно создать одну подпапку.
Не делай всё за меня.
```
