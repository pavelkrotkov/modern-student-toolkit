# 6. Поручи агенту работу с файлами

**Время:** 45–60 минут. **Результат:** агент создаст один проверяемый файл в выбранной папке.

## Перед началом

Пройдены уроки 0–5. Ты умеешь читать текстовый файл, находить текущую папку и проверять результат в Finder. Git и личные навыки Codex пока не нужны.

## 1. Подготовь доступ

**Проверено: 2026-10-07.** Установи приложение ChatGPT с [официальной страницы загрузки](https://chatgpt.com/download/), если его ещё нет. Можно воспользоваться уже изученным Homebrew:

```bash
brew install --cask chatgpt
```

Открой приложение из Applications и войди в свою учётную запись. Выбери **Codex** в переключателе продуктов. В новом чате найди выбор проекта или локальной папки: интерфейс может показывать **Open folder / Open local folder**. Выбери `~/University/Projects/Codex-Practice`. Если предлагается выбор среды, нужна локальная работа на этом Mac.

Если доступен только Work с локальными папками, выполняй упражнение там. Если локальная работа недоступна, используй вариант в конце урока. Покупать подписку ради этого шага не требуется.

[Различия Chat, Work и Codex](https://learn.chatgpt.com/docs/use-chatgpt).

## 2. Сначала прочитай, что агент видит

Отправь:

```text
Я учусь работать с файлами. Пока ничего не меняй.
Назови выбранную папку и перечисли файлы непосредственно внутри неё.
Прочитай one.txt и two.txt. Покажи их содержимое.
Если этих файлов нет или нет доступа, сообщи об этом и остановись.
```

Сравни путь, список и строки с Finder и TextEdit. Если они не совпадают, сначала исправь выбор папки. Для упражнения достаточно `Codex-Practice`; домашняя папка целиком не нужна.

**Работа с локальными файлами не означает, что все сведения остаются на Mac.** Запросы, фрагменты файлов, снимки экрана и результаты инструментов могут передаваться сервису для выполнения задачи; сообщения и контекст могут храниться в облаке в зависимости от режима и настроек. Это не означает автоматическую отправку всей папки. Для упражнения используй только учебные данные. [Документация OpenAI о локальной работе и обработке данных](https://learn.chatgpt.com/docs/enterprise/chatgpt-work-local-security).

## 3. Закажи один новый результат

Проверь в Finder, что `summary.md` ещё нет. Если он остался от прошлой попытки, выбери новое имя, например `summary-2.md`, и замени его в запросе.

```text
Создай в выбранной папке новый файл summary.md по one.txt и two.txt.
Нужны заголовок, два пункта с точным содержимым исходных строк
и строка «Источники: one.txt, two.txt».
Исходные файлы не изменяй. Если summary.md уже существует, остановись.
После выполнения перечисли созданные и изменённые файлы.
```

Теперь задача достаточно конкретна для выполнения. Если агент предлагает неожиданные установки, другие папки или отправку данных, останови задачу и уточни запрос.

Проверь файл сам:

```bash
cd ~/University/Projects/Codex-Practice
cat summary.md
cat one.txt
cat two.txt
```

Должны появиться две исходные строки и список источников; исходные файлы должны сохранить прежнее содержимое. Открытие файла пользователем — часть проверки, даже если агент уже сообщил об успехе.

## 4. Дай точную обратную связь

Если оформление не подходит, попроси одно изменение:

```text
В summary.md замени только заголовок на «Мои первые файлы».
Содержимое пунктов и источники сохрани.
```

Снова открой результат. В уроке 7 научимся видеть изменения построчно и восстанавливать версии.

## 5. Браузер и Computer Use — дополнительная практика

Для чтения и создания файлов обычно достаточно прямой работы агента с выбранной папкой. Браузер нужен для сайта; **Computer Use** — для управления графическим приложением.

Если функция доступна, в приложении открой **Plugins → Computer Use**, установи или включи плагин. Следуй запросам macOS на **Screen Recording** и **Accessibility**. В **Settings → Computer use** проверь доступ к приложениям. Для первого опыта разрешай только необходимое действие; постоянный доступ не является требованием курса.

Попробуй в приложении Calculator:

```text
@Computer Открой Calculator и вычисли 12 × 8.
Покажи результат. Другие приложения и настройки не изменяй.
```

Проверь число **96** на экране. Если нужна работа с уже открытыми сайтами, настройка расширения браузера описана отдельно в [официальной инструкции](https://learn.chatgpt.com/docs/chrome-extension).

**Выбранная папка не ограничивает автоматически всё управление компьютером.** Через интерфейс агент может видеть и изменять другие приложения согласно выданным разрешениям. Учись задавать конкретную область действий. [Настройка и границы Computer Use](https://learn.chatgpt.com/docs/computer-use).

## Если агент недоступен

Скопируй текст `one.txt` и `two.txt` в Chat и попроси подготовить содержимое `summary.md`. Сохрани его вручную в TextEdit как простой текст; проверь расширение, чтобы не получилось `.md.txt`. Если Chat тоже недоступен, составь файл сам по условиям шага 3.

Так можно освоить постановку задачи и проверку. Практику доступа агента к папке отметь как отложенную и вернись к ней позже.

## Проверка результата

- [ ] В `summary.md` две точные строки и имена источников.
- [ ] Исходные файлы сохранили своё содержимое.
- [ ] Могу назвать папку, с которой работал агент, или объяснить ручной вариант.
- [ ] Понимаю отличие работы с файлами от управления приложением.

**Попробуй сам:** сформулируй запрос на ещё один файл по этим же источникам: задай имя, формат и способ проверки. Сам реши, какие сведения нужно дать агенту.

**Завтра:** проверь новый результат агента, открыв исходники и созданный файл.

**Слова занятия:** агент — помощник с инструментами для действий; контекст — сведения, переданные для задачи; область доступа — ресурсы, к которым выданы разрешения. [Подсказки](hints.md#agent) · [Справка по интерфейсу](interface-reference.md#agent).
