# Modern Student Toolkit

Практический курс для старшеклассника или студента первого курса без технического опыта: Mac, работа с ИИ, источники, документы, таблицы, Git и немного Python.

**Начало курса: <https://pavelkrotkov.github.io/modern-student-toolkit/>**

Локальная копия репозитория не нужна до урока Git. Первые полезные результаты — проверенный ответ по источникам, собственная заметка и бюджет учебной поездки — появляются до установки средств разработки.

## Основной маршрут

0. Подготовка Mac и папок.
1. Файлы, поиск, сохранение и восстановление.
2. Постановка задачи ИИ и проверка ответа.
3. Источники в Zotero и заметки в Obsidian.
4. Документ, таблица с формулами и диаграмма.
5. Terminal и Homebrew.
6. Работа агента с выбранной папкой.
7. Git, GitHub и восстановление версии файла.
8. Чтение, запуск и изменение программы Python.
9. Итоговая работа и самостоятельная проверка.

Ориентир — 8–12 часов активной работы, без долгих установок. MIT Missing Semester, личный навык `$teach-me` и обслуживание Mac доступны как дополнительные занятия. При ограничениях доступа отдельные технические действия можно отложить; обходные варианты описаны в уроках.

## Материалы

В `docs/practice` находятся два вымышленных учебных источника, два CSV и программа расчёта без сторонних библиотек. Они доступны с сайта до клонирования репозитория. В уроках есть контрольные результаты, самостоятельные упражнения и короткое повторение на следующий день.

Рабочие папки ученика: `~/University/Notes`, `Projects`, `Sources`, `Scratch`. Источники и собственные работы сохраняются отдельно.

## Обратная связь

На странице [«Если застрял»](https://pavelkrotkov.github.io/modern-student-toolkit/help/#feedback) есть короткий шаблон: урок, шаг, затраченное время, ожидание и фактический результат. Учётная запись GitHub для обратной связи не обязательна.
