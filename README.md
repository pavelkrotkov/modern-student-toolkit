# Modern Student Toolkit

Практический курс для старшеклассника или студента первого курса без технического опыта: Mac, работа с ИИ, источники, документы, таблицы, Git и немного Python.

**Начало курса: <https://pavelkrotkov.github.io/modern-student-toolkit/>**

Локальная копия репозитория не нужна до урока Git. Первые полезные результаты — проверенный ответ по источникам, собственная заметка и бюджет учебной поездки — появляются до установки средств разработки.

## Два маршрута

**Учебная работа, 7–10 часов:** подготовка и восстановление доступа; настройка Bitwarden и браузера; Mac и файлы; проверка ИИ и реальное исследование; источники и заметки в Markdown; документы и таблицы в ONLYOFFICE; поиск ошибок данных; совместная работа и сдача через DocSpace либо обмен копиями. Собственная работа в конце этого маршрута — полноценное завершение курса.

**Техническая самостоятельность, ещё 5–7 часов:** Terminal и Homebrew; агент и выбранная папка; Git и GitHub; чтение и изменение Python; итоговая задача с новыми условиями. Продолжение необязательно для первого результата.

Оценки не включают долгие загрузки, ожидание партнёра и повторения; их ещё нужно проверить с начинающими. Примерно через неделю после любого маршрута предусмотрена отдельная задача на незнакомых данных (35–50 минут). MIT, `$teach-me`, дополнительные таблицы и обслуживание Mac доступны по потребности.

## Материалы

В `docs/practice` находятся вымышленные источники, исходные и намеренно испорченные CSV, отдельный набор для отложенной проверки и программа расчёта без сторонних библиотек. Всё доступно с сайта до клонирования репозитория. В уроках есть авторские подсказки, закрытые контрольные ответы, самостоятельные задания и повторение. Личный журнал отличает работу без помощи от работы со справкой или ИИ.

Рабочие папки ученика: `~/University/Notes`, `Projects`, `Sources`, `Scratch`. Источники и собственные работы сохраняются отдельно.

## Обратная связь

На странице [«Если застрял»](https://pavelkrotkov.github.io/modern-student-toolkit/help/#feedback) есть короткий шаблон: урок, шаг, затраченное время, ожидание и фактический результат. Учётная запись GitHub для обратной связи не обязательна.
