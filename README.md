# Modern Student Toolkit

Практический курс для студента, который **не собирается становиться программистом**, но хочет уверенно пользоваться Mac, ChatGPT, Codex, GitHub, Obsidian и простыми средствами автоматизации.

**Начинать нужно с сайта, а не с этого репозитория:**

**https://pavelkrotkov.github.io/modern-student-toolkit/**

Курс рассчитан на человека, который ещё не знает, что такое `git clone`, рабочая директория или «корень репозитория». Поэтому в первых уроках не нужна локальная копия курса. Мы загрузим её позднее — в качестве упражнения по Git.

## Для ученика

1. Открой сайт по ссылке выше в обычном браузере.
2. Начни с **«0. Начало»**.
3. Иди по порядку: каждый урок явно пишет, что должно быть уже сделано.
4. Если что-то не получается, используй страницу **«Если застрял»** и ChatGPT в браузере.
5. Не запускай команды из файлов этого репозитория только потому, что увидел их на GitHub.

## Что внутри

- Finder, файлы, папки и Terminal с нуля;
- Homebrew и понятная установка/обновление программ;
- Chat, Work и Codex: как выбирать нужный режим;
- работа Codex с выбранными папками, браузером и функцией управления компьютером (Computer Use);
- MIT Missing Semester 2026 с помощью ИИ на русском языке;
- Git и GitHub на уровне уверенного пользователя;
- Obsidian и отдельный закрытый репозиторий GitHub для заметок;
- личный навык Codex `$teach-me`;
- Python как техническая грамотность;
- ONLYOFFICE, Zotero и перевод;
- минимальное обслуживание Mac.

Курс написан на естественном русском языке. Английские технические термины приводятся в скобках при первом знакомстве с ними, если это помогает учёбе. Названия программ, надписи интерфейса, команды, пути, имена файлов, код и тексты ошибок сохраняются без изменений.
